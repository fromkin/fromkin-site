Fromkin · 中级就业指导师培训教程

第五章 困难个案的全程管理

李姐今年52岁，失业三年，换了三个就业指导师。前两个指导师都是这样：把她叫到服务站，聊了半小时，留了电话，就没了下文。李姐私下跟邻居说："每次去都问我同样的问题，填完表就让我回家等消息，等了三年，连个影子都没见着。"

第四位指导师小陈接手后，没急着谈岗位。第一次面谈，他花了整整一下午，把李姐这三年做过的每一件事都捋了一遍：去过哪儿找工作、卡在哪一步、家里现在谁挣钱、孩子上学要花多少。回来他对站长说："以前是散兵游勇，今天聊点这个明天聊点那个，当然没进展。得给她立个案，按流程走。"

接下来半年，小陈给李姐建了专档，做了能力诊断，定了"三个月内先解决收入、半年内转正规就业"的两步目标，安排了一轮免费技能培训，又联系到一家社区服务中心的公益性岗位做过渡。每两周一次电话回访，每次都有记录。第五个月，李姐被一家物业公司录用为保洁主管，转正后月薪比原来翻了一番。结案那天，李姐拉着小陈的手说："你跟他们不一样，你是真把我这件事当事来办的。"

小陈做的事，名字叫个案管理。它和普通咨询的区别在于：咨询解决一个问题就结束，个案管理是把一个人从"失业"带到"稳定就业"的全过程管起来。本章讲的就是这套方法。

一、个案管理的六步流程：建档—诊断—计划—干预—跟踪—结案

个案管理不是一个技巧，而是一套闭环的工作程序。对每一名困难人员，这六步按顺序走，少一步都不行。

**第一步，建档。** 拿到转介过来的困难人员，第一件事不是见面，是先把已有资料归档：基本信息、失业时间、家庭情况、以往服务记录。然后才约第一次面谈。档案建得早，后面每一步都有依据。

**第二步，诊断。** 通过面谈和评估工具，弄清楚"他到底卡在哪儿"。诊断的结论要写成书面记录，而不是指导师脑子里有个大概印象。

**第三步，计划。** 和当事人一起制定个别化就业援助计划：目标定几步走，每一步用什么手段，谁来做，什么时候完成。这份计划要当事人签字确认——签字这个动作本身，就是在让他对自己负责。

**第四步，干预。** 按计划执行：联系培训、推荐岗位、安排见习、做心理疏导。干预不是一次性动作，而是持续的服务投入。

**第五步，跟踪。** 干预启动后定期回访，检查计划执行到哪了，出了什么偏差，及时调整。跟踪的频率根据个案进展定，初期一般每两周一次。

**第六步，结案。** 达到预设的就业目标并稳定一段时间后，正式结案。结案不是"不管了"，而是把经验沉淀下来，把后续的常规服务交回给一般性服务渠道。

实务经验表明，很多个案"烂尾"都发生在两步之间：建档之后没做诊断，凭感觉干预；干预之后没跟踪，人就不见了。六步流程的价值，就是不让任何一个环节"自然蒸发"。

**诊断要回答的四个问题。** 诊断不是"聊聊天、凭感觉"，而是要系统回答四个问题，建议用下表做诊断记录的框架：

| 诊断维度 | 要弄清的问题 | 李姐的例子 |

|---|---|---|

| 就业能力 | 有什么技能、证书？技能是否过时？ | 只有传统家政经验，无证书 |

| 求职行为 | 会写简历吗？面试表现如何？用哪些渠道？ | 三年没投过简历，不会用手机求职 |

| 心理状态 | 自信心如何？有没有习得性无助？ | 多次被拒后自我否定，"我这把年纪没人要" |

| 现实约束 | 家庭负担、健康、交通、时间有何限制？ | 丈夫打零工，孙子需接送，白天时间碎片化 |

四个维度查完，障碍清单就出来了，干预才有靶心。诊断结论要写成一句话，贴在档案首页，例如："主要障碍：技能单一无证书＋求职技能缺失＋自信心受损；现实约束：白天需接送孙子，宜安排时间灵活的岗位或培训。"

**警惕"想当然诊断"。** 常见的误诊有三种：一是把"不配合"当成"不努力"，其实是当事人没听懂计划；二是把"要求多"当成"挑剔"，其实是他对市场行情不了解；三是把"沉默寡言"当成"没想法"，其实是他还没建立信任。诊断阶段多问一句"您是怎么想的"，少下一次"他就是懒"的结论。

二、建档规范：一份好档案长什么样

档案是全程管理的地基。地基打得歪，上面盖什么都不稳。一份规范的困难人员个案档案，应当包含以下内容：

| 档案模块 | 应收录的内容 |

|---|---|

| 基本信息 | 姓名、性别、年龄、联系方式、失业时间、就业失业登记状态 |

| 家庭与经济状况 | 家庭成员、主要收入来源、月均支出、是否有抚养负担 |

| 就业经历 | 历年工作单位、岗位、离职原因、失业期间做过什么 |

| 能力与意愿 | 学历、技能证书、能做什么、想做什么、不愿意做什么 |

| 诊断记录 | 每次评估的时间、工具、结论 |

| 服务计划 | 援助计划全文、当事人签字 |

| 过程记录 | 每次面谈、电话、推荐的日期和内容摘要 |

| 结案材料 | 结案评估、就业去向、经验总结 |

几个建档的实务要点：

**第一，信息一次收齐，避免反复打扰。** 困难人员最反感的就是"每个指导师都问我一遍同样的问题"。第一次面谈前，先调阅已有资料；面谈时用一张结构化的信息采集表，一次把该问的问完。

**第二，客观记录与主观判断分开写。** "当事人表示不愿从事夜班工作"这是客观记录；"当事人怕吃苦"这是主观判断。档案里只写前者。主观标签一旦写进档案，会影响下一任指导师的判断——李姐换了三任指导师都没进展，部分原因就是档案里除了几张表格什么都没有，新人只能从头问起。

**第三，档案要"活"。** 每次服务后24小时内补记过程记录。拖一周再补，细节就记不全了。过程记录不用长，三五句话说清"这次做了什么、当事人什么反应、下一步是什么"即可。

**第四，注意保密。** 个案档案涉及个人隐私，存放和流转要遵守保密要求，不在公开场合讨论个案细节，这是职业底线。

**第五，交接要有"交接单"。** 指导师调岗、离职时，个案必须正式交接，不能"口头说一声"了事。交接单至少包括：在管个案清单、每位个案当前进展到哪一步、下一次回访日期、需要特别注意的事项（如当事人情绪不稳定、家庭有变故）。李姐换了三任指导师都没进展，根子就在交接上：前任只留了几张信息表，没有过程记录，没有诊断结论，新人只能从零开始问，当事人被问烦了，信任也没了。规范的交接，是对当事人负责，也是对接任者负责。

三、个别化就业援助计划的制定：目标要具体、可衡量

诊断清楚"卡在哪儿"，下一步就是定计划。个别化就业援助计划是个案管理的"施工图"，好计划有三个特征：目标具体、步骤可行、当事人认同。

**目标要具体、可衡量。** "帮助实现就业"不是目标，是愿望。合格的目标长这样：

不合格："提高李姐的就业能力。"

合格："三个月内，李姐完成家政服务技能培训并取得结业证明；六个月内，通过公益性岗位或市场渠道实现就业，月收入不低于当地最低工资标准。"

实务中可以用"目标三问"来检验：这目标能不能用数字或事实验证？完成时间定没定？当事人自己认不认？三个都答得上，才算合格。

**步骤要拆小、排先后。** 困难人员的就业障碍往往是复合的：技能不够、信心不足、家庭拖累。计划要把大目标拆成小步骤，按"先易后难、先急后缓"排序。比如李姐的计划：

第1个月：完成能力评估，确定培训方向；

第2—3个月：参加技能培训，同步做求职心理调适；

第4个月：通过公益性岗位先解决收入问题；

第5—6个月：在岗积累经验，同步关注转岗机会。

**手段要写清"谁来做"。** 计划里每一项干预都要明确责任人：培训由谁联系、岗位由谁推荐、回访由谁负责。写不清责任人的计划，等于没人负责。

**当事人要签字。** 计划制定是指导师和当事人"一起"做的事，不是单方面下达的任务。面谈中可以用这样的话术：

> "李姐，咱们刚才聊的我都记下来了。我理了个计划：先培训、再过渡、最后转正，您看看这样安排行不行？行的话咱们都签个字，往后就按这个走，每两周我给您打个电话，咱们一起盯进度。"

签字确认的意义在于建立"契约感"：这是我们共同的约定，不是我布置给你的作业。实务经验表明，参与过计划制定的当事人，配合度明显更高。

四、干预策略的选择与组合：培训、见习、公益性岗位、心理支持如何搭配

计划定好了，进入干预阶段。困难人员的问题很少是单一的，所以干预手段也很少只用一种。关键是"搭配"：不同手段解决不同层面的问题，组合起来形成合力。

**四类常用干预手段的分工：**

**职业培训**：解决"能力不够"的问题。适合技能老化、想转行但缺证书的人。选择培训项目时，先看当地产业需求，再看当事人基础——让一个初中文化的50岁大姐去学编程，就是资源错配。

**就业见习**：解决"没经验、不敢上"的问题。适合长期脱离职场、需要重新适应工作节奏的人。见习期是缓冲带，犯错成本低。

**公益性岗位**：解决"等不起"的问题。适合家庭经济压力大、必须先有收入的人。公益性岗位是"过渡"，不是"终点"，上岗之初就要跟当事人讲清楚：这一步是为了稳住生活，下一步还要往市场走。

**心理支持**：解决"不想动、不敢试"的问题。长期失业者常见的状态是习得性无助——不是没能力，是不相信自己还有能力。心理支持不一定是专业咨询，更多时候是持续的鼓励和"小赢"体验的积累：先帮他完成一件小事，让他重新相信自己能行。

**组合的逻辑：按"障碍排序"搭配。** 以李姐为例：她最急的是没收入（经济障碍），同时技能单一（能力障碍）、三年没上班信心不足（心理障碍）。小陈的组合是：先用公益性岗位托底收入，同步安排技能培训提升能力，培训中的小测验通过、老师表扬，一点点重建她的信心。三管齐下，半年见效。

**干预中的话术示例**（推荐公益性岗位时）：

> "李姐，我给您找了个社区服务中心的岗位，先干着，收入有着落，家里也踏实。但这只是第一步，咱们的目标是半年后转到物业公司做主管，工资能翻一番。这几个月您一边上班一边把培训证拿下来，到时候咱们底气就足了。"

这段话术同时完成了三件事：给出当下方案、讲清过渡性质、锚定远期目标。困难人员最怕的是"被安排"——讲清楚"为什么是这一步"，他才愿意配合走下一步。

**干预的红线**：不包办代替。指导师可以帮他找资源、搭桥梁，但不能替他做决定、替他面试。包办出来的"就业"长久不了，当事人自己走通的路才走得远。

**干预中的常见陷阱。** 一是"撒胡椒面"：培训、见习、岗位一起上，看似全面，实则当事人疲于应付，哪个都没做好。干预手段一次聚焦一到两个，见效再加。二是"只管开头不管中间"：把人送进培训班就以为万事大吉，其实培训中途的放弃率最高，干预的关键恰恰在中途的跟进打气。三是"用新计划掩盖旧问题"：上一个计划没执行好，不分析原因就另起炉灶换新计划，结果每个计划都浅尝辄止。计划执行不下去，先回头看诊断对不对，而不是急着换花样。

五、跟踪回访：防止"服务断档"

个案管理最容易断的地方，是干预启动之后。推荐了岗位、送去了培训，指导师觉得"事办完了"，当事人那边遇到点困难又不好意思开口，慢慢就断了联系。这叫"服务断档"，是困难个案前功尽弃的首要原因。

**跟踪要制度化，不要凭记性。** 每个在管个案建立回访台账：下次回访日期、回访方式、上次遗留问题。到期必须联系，台账就是约束。初期建议每两周一次，稳定后可延长到每月一次。

**回访不是"查岗"，是"撑腰"。** 话术决定了当事人愿不愿意接你的电话。对比两种开场：

查岗式："你最近怎么样？找到工作没有？"——当事人一听就想挂电话。

撑腰式："李姐，我是小陈。您上周说培训课跟得有点吃力，这周怎么样？有没有哪块需要我帮您问问老师？"——当事人感受到的是关心，不是考核。

**回访要抓"关键节点"。** 培训结业前、见习结束时、上岗第一个月、试用期转正前，这些都是最容易掉链子的节点。节点回访要主动、要提前，不要等当事人出事了才问。

**出现偏差及时调计划。** 跟踪的意义不只是"看看"，而是"调整"。比如原计划让当事人参加三个月培训，他上了两周就想放弃，这时候不是批评他没毅力，而是回到诊断：是课程太难？是家里有事？还是他根本对这个方向没兴趣？找到原因，调整计划——换课程、调时间、甚至换目标。计划是活的，不是刻在石头上的。

**回访记录的写法。** 每次回访后记三行：当事人现状一句话、本次沟通要点一句话、下一步行动一句话。例如："李姐培训已上两周，反映实操跟不上；已联系培训老师安排课后单独辅导半小时；下周二电话确认辅导效果。"三行记清楚，任何人接手都能续上。

**长期无进展个案的处置。** 有的个案跟了半年一年，就业目标始终没实现。这时候不要硬撑，也不要悄悄放弃。正确做法是：组织一次个案研讨，请站长或资深同事一起复盘——是诊断错了，还是手段不对，还是目标定高了？复盘后形成书面调整意见，要么修正计划继续跟，要么在充分沟通后转入低强度的常规服务。最忌讳的是"名义上在管、实际上不管"，档案里最后一条记录停留在三个月前。

实务经验总结过一句大白话：**个案管理，管的就是"不断线"。** 线不断，希望就不断。

六、结案标准与经验沉淀

有开始就要有结束。结案不是"终于甩掉一个包袱"，而是对这段服务画一个负责任的句号。

**结案的标准要事先定好，写在计划里。** 常见的结案标准包括：实现就业并稳定就业满三个月；当事人自主创业且经营稳定；经评估转入其他服务渠道（如转入常规失业登记服务）；当事人主动要求终止且经沟通确认。标准事先定，结案时才不扯皮。

**结案前做一次全面评估。** 对照计划里的目标一条条过：哪些达到了，哪些没达到，没达到的原因是什么。这次评估是指导师的"交卷"，要诚实。李姐的结案评估里，小陈写道："六个月目标基本实现；不足是培训期间有两次想放弃，靠临时加做心理疏导才稳住，说明初期对心理障碍估计不足。"

**结案面谈：好好告别。** 跟当事人正式谈一次，告诉他"咱们的个案服务到这里就结束了"，同时讲清楚以后遇到问题找谁。这次面谈有两个作用：一是给当事人一个"毕业"的仪式感，强化他的成就感；二是完成服务交接，不让他觉得"人走茶凉"。

话术示例：

> "李姐，咱们当初定的半年目标，今天算是实现了。从今天起，您的个案就正式结案了——这不是不管您了，是您'毕业'了。以后工作中遇到什么事，直接打服务站电话找我，或者找值班的同事，都行。您这半年的经历我整理成了一个小案例（把名字隐去），想分享给其他跟您情况类似的人，您看可以吗？"

这段话术完成了四件事：宣布结案、肯定成绩、讲清后续求助渠道、征求案例使用同意。最后一点很重要：用当事人的故事做案例，必须经本人同意并隐去可识别信息。

**结案后的衔接：转入常规服务。** 个案结案不等于服务终止，而是服务强度降级：从"专人跟踪"转入"常规服务"，比如失业登记的常规回访、招聘信息的群发推送。交接时把个案的基本情况和注意事项告诉常规服务同事，避免当事人觉得"结案就是被抛弃"。

**经验沉淀：把个案变成组织的知识。** 这是最容易被省略的一步，也是个案管理对机构最有价值的一步。每个结案个案写一份简短的案例总结：基本情况、主要障碍、干预组合、关键转折点、经验教训。积累多了，就是本站的"困难人员服务案例库"。新人来了先读案例库，上手快得多；遇到类似情况，直接调取可参照的方案。

李姐的案例后来被小陈写成了800字的总结，存在了站里的案例库。半年后，另一位指导师接手一名情况类似的失业人员，翻出这份总结，第一句话就跟当事人说："之前有个跟您情况差不多的大姐，半年就稳定就业了，咱们也按那个路子走。"——这就是经验沉淀的价值：一个人的经验，变成一群人的办法。

**指导师的自我关怀。** 困难个案耗时长、见效慢，指导师容易产生挫败感和职业倦怠。实务中有三条自我保护的经验：一是合理设定期望——不是每个个案都能成功，把"尽力走完流程"和"实现就业"分开看，前者是你的责任，后者不完全由你决定；二是定期做个案研讨，把难啃的个案拿到团队里一起讨论，一个人扛不如一群人想办法；三是记录自己的"小赢"——每帮助一个人前进一步，都值得记下来，这是对抗倦怠最好的燃料。

本章小结

个案管理是把困难人员从失业带到稳定就业的全过程管理，六步流程"建档—诊断—计划—干预—跟踪—结案"缺一不可，最容易烂尾的是步骤之间的衔接。

好档案的四条标准：信息一次收齐、客观记录与主观判断分开、每次服务24小时内补记、注意保密。

个别化就业援助计划要目标具体可衡量、步骤拆小排先后、责任到人，并由当事人签字确认，建立契约感。

干预讲究组合：培训补能力、见习练适应、公益性岗位托底收入、心理支持重建信心，按障碍排序搭配，不包办代替。

跟踪回访要制度化、话术要"撑腰"不要"查岗"、抓住关键节点、出现偏差及时调整计划——管的就是"不断线"。

结案标准事先定在计划里，结案前全面评估、做好告别面谈，并把个案写成案例总结沉淀为组织知识。
