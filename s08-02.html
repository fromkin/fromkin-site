Fromkin · 就业指导师考试教程

第1章 就业相关政治理论

【本章考纲】

1. 掌握就业在我国经济社会发展中的地位（民生之本、最大的民生、“六稳”“六保”首位）

2. 理解就业优先战略的内涵、意义与实施要求

3. 熟悉关于就业工作的公开重要论述的基本观点（按主题归类）

4. 掌握高质量充分就业的内涵、特征、目标任务与实现路径

5. 熟悉就业优先导向的宏观经济社会政策体系的主要内容

6. 掌握就业与经济发展、民生改善、社会稳定的内在关系

7. 掌握就业工作的主要原则、方法与相关重要概念辨析

【知识精讲】

一、就业在经济社会发展中的基础地位

1. 就业是民生之本

我国公开的政治表述反复强调：就业是民生之本。一个人有就业，就有收入来源，就能维持基本生活，就能在劳动中实现自身价值。对一个家庭来说，就业是主要收入来源，是脱贫致富、改善生活的基本途径；对国家来说，就业状况是观察经济运行、民生改善和社会稳定的重要窗口。

2. 就业是最大的民生

“就业是最大的民生”这一公开表述，说明党和国家把就业摆在民生工作的首要位置。教育、医疗、社会保障等各项民生工作，最终都要靠就业来支撑——没有就业和收入，其他民生改善就无从谈起。因此，促进就业是保障和改善民生的头等大事。

3. 就业是经济发展的晴雨表

就业是观察经济运行状况的重要指标。经济增长是就业的根本支撑，经济平稳运行是就业稳定的基础；反过来，就业充分、收入增长，又能拉动消费、促进经济发展。二者相互促进、良性循环。

4. 就业与“六稳”“六保”

在“六稳”“六保”中，“六稳”之首是“稳就业”，“六保”之首是“保居民就业”。这表明就业被摆在宏观调控和风险防范的优先位置，体现了以人民为中心的发展思想。考试中常把“六稳”“六保”之首作为就业地位的考点。

5. 劳动就业权是公民的基本权利

宪法规定，公民有劳动的权利和义务。国家通过各种途径创造劳动就业条件，加强劳动保护，改善劳动条件，并在发展生产的基础上，提高劳动报酬和福利待遇。促进就业是国家应当履行的宪法职责，也是就业指导师开展工作的法理基础。

二、就业优先战略

1. 就业优先战略的提出与内涵

我国实施就业优先战略，就是把促进就业作为经济社会发展的优先目标，放在更加突出的位置。就业优先不是指所有政策都只为就业服务，而是指在制定宏观经济政策和经济社会发展规划时，把扩大就业、稳定就业作为优先考虑的因素，使经济发展过程成为扩大就业的过程。

2. 实施就业优先战略的重大意义

- 发展意义：就业是经济发展的重要基础，就业优先有利于实现经济高质量发展

- 民生意义：就业是民生之本，就业优先最直接地体现以人民为中心的发展思想

- 稳定意义：就业是社会稳定的基石，就业稳定是社会大局稳定的重要保障

- 长远意义：适应我国劳动力总量依然庞大、结构性矛盾突出的基本国情

3. 实施就业优先战略的主要要求

- 强化就业优先的宏观调控：财政、货币、产业、投资、消费、区域等政策都要把促进就业作为优先目标，形成有利于扩大就业的宏观经济环境

- 健全就业优先政策体系：完善积极的就业政策，强化对重点行业、重点群体的就业支持

- 促进创业带动就业：放宽市场准入，优化创业环境，发挥创业对就业的倍增效应

- 健全就业公共服务体系：完善覆盖城乡的公共就业服务网络，提高就业服务均等化、标准化、专业化水平

- 强化就业困难群体兜底帮扶：对就业困难人员实施精准帮扶，保障其基本就业权益

三、关于就业工作的重要论述（按主题归类）

关于就业工作的公开重要论述是就业指导工作的根本遵循。学习时要注意把握各主题的基本观点，避免断章取义。

主题一：坚持就业优先

- 就业是最大的民生，要始终把促进就业摆在突出位置

- 实施就业优先战略，把就业优先政策落到实处

- 把稳就业、保居民就业作为“六稳”“六保”的首要任务

主题二：促进高质量充分就业

- 就业是最基本的民生，促进高质量充分就业是新时代新征程就业工作的新定位、新使命

- 高质量充分就业，就是要有较高的就业率和较好的就业质量

- 健全就业公共服务体系，加强困难群体就业兜底帮扶

主题三：高校毕业生等青年就业

- 高校毕业生就业事关千家万户，事关国家发展未来

- 要把高校毕业生就业作为就业工作的重中之重

- 引导高校毕业生树立正确的就业观，到基层、到祖国最需要的地方建功立业

主题四：农村劳动力就业

- 促进农村劳动力转移就业和返乡创业就业

- 做好脱贫人口稳岗就业工作，巩固拓展脱贫攻坚成果

- 发展乡村产业，带动农民就近就业

主题五：创业带动就业

- 完善创业扶持政策，营造良好的创业环境

- 发挥创业带动就业的倍增效应

- 鼓励支持劳动者自主创业、自谋职业

主题六：完善就业公共服务体系

- 健全覆盖城乡的公共就业服务体系

- 完善重点群体就业支持体系

- 加强就业信息化建设，提高服务精准化水平

主题七：维护劳动者合法权益

- 消除影响平等就业的不合理限制和就业歧视，使人人都有通过勤奋劳动实现自身发展的机会

- 构建和谐劳动关系，保障劳动者合法权益

- 完善社会保障体系，解除劳动者的后顾之忧

主题八：新就业形态与灵活就业

- 支持和规范发展新就业形态

- 加强灵活就业和新就业形态劳动者权益保障

- 完善适应灵活就业的社会保障政策

四、高质量充分就业

1. 高质量充分就业的提出与地位

促进高质量充分就业，是新时代新征程就业工作的新定位、新使命。这一公开表述是在我国发展进入新阶段、就业总量压力依然存在、结构性矛盾更加突出的背景下提出的，标志着我国就业工作从“扩大就业规模”向“实现更高质量的充分就业”转变。

2. 高质量充分就业的内涵

“高质量充分就业”包含“充分”和“高质量”两层含义：

- 更充分：就业规模持续扩大，就业结构不断优化，就业机会更加公平，就业环境更加包容，使有就业意愿的劳动者都能获得就业机会

- 更高质量：就业质量稳步提升，劳动报酬合理增长，劳动条件不断改善，劳动关系更加和谐，劳动者职业发展通道更加畅通，就业的稳定性、收入的持续性、权益的保障性、社会认可度不断增强

3. 高质量充分就业的主要特征

- 就业容量大：经济增长能够创造充足的就业岗位

- 就业结构优：三次产业、城乡、区域就业结构更加协调

- 就业机会公平：消除就业歧视，人人享有平等的就业机会

- 就业质量高：收入水平、劳动保护、社会保障同步提升

- 劳动关系和谐：劳动者权益得到有效保障

4. 促进高质量充分就业的重点任务

- 坚持经济发展就业导向，扩大就业容量、提升就业质量

- 着力解决结构性就业矛盾，缓解“就业难”与“招工难”并存问题

- 完善重点群体就业支持政策体系

- 深化就业体制机制改革，消除影响平等就业的不合理限制和就业歧视

- 加强劳动者权益保障，构建和谐劳动关系

5. 促进高质量充分就业的实现路径

- 经济发展路径：坚持以经济建设为中心，以高质量发展促进高质量充分就业

- 创业带动路径：鼓励创业创新，以创业带动就业，发挥创业的就业倍增效应

- 技能提升路径：大力发展职业技能培训，提高劳动者素质，缓解结构性就业矛盾

- 服务完善路径：健全就业公共服务体系，提高就业服务的精准性、有效性

- 权益保障路径：完善劳动法律法规和社会保障制度，维护劳动者合法权益

五、就业优先导向的宏观经济社会政策体系

1. 构建就业友好型发展方式

公开表述提出，要构建就业友好型发展方式，促进高质量充分就业。所谓就业友好型发展方式，就是在发展规划、产业政策、区域政策、投资政策中充分考虑就业因素，使经济发展与扩大就业良性互动。

2. 宏观政策的就业优先导向

- 财政政策：加大对就业的支持力度，完善就业补助资金使用管理

- 货币金融政策：引导金融机构加大对吸纳就业能力强的行业企业的支持

- 产业政策：发展吸纳就业能力强的产业和企业，培育新的就业增长点

- 投资政策：重大项目建设要注重带动就业，评估项目对就业的影响

- 消费政策：扩大内需、促进消费，带动服务业等劳动密集型行业发展

3. 重大政策就业影响评估

在制定涉及就业的重大政策时，要开展就业影响评估，评估政策对就业规模、就业结构、就业质量的影响，防范政策调整对就业造成大的冲击。这一机制是就业优先战略在政策制定环节的具体体现。

4. 就业与经济社会发展规划衔接

把就业目标纳入国民经济和社会发展规划，使就业规划与经济社会发展规划相衔接，实现就业工作与经济社会发展的统筹推进。

六、就业与发展、民生、稳定的关系

1. 就业与经济发展

经济发展是就业的根本支撑。没有持续健康的经济发展，就没有稳定的就业增长；同时，充分就业和收入增长又是扩大内需、促进经济发展的重要动力。经济增长与就业增长良性互动，是高质量发展的内在要求。

2. 就业与民生改善

就业是民生之本。就业状况直接决定居民收入水平，进而决定教育、医疗、住房、养老等民生领域的改善程度。促进就业是最直接、最有效的民生工程。

3. 就业与社会稳定

就业是社会稳定的基石。大规模失业会引发一系列社会问题。保持就业局势总体稳定，是维护社会大局稳定的重要基础。特别要关注高校毕业生、农民工等重点群体的就业，防止出现规模性失业风险。

4. 三者统一于以人民为中心的发展思想

发展为了人民，发展依靠人民，发展成果由人民共享。就业工作把经济发展、民生改善、社会稳定统一起来，是以人民为中心发展思想在就业领域的具体体现。

七、就业工作的主要原则与方法

1. 坚持市场导向与政府促进相结合

我国实行“劳动者自主择业、市场调节就业、政府促进就业”的就业方针。市场在人力资源配置中起决定性作用，劳动者自主选择职业，用人单位自主决定用工；政府则通过制定政策、提供服务、加强监管、实施援助等方式促进就业。就业指导工作必须遵循这一基本原则，既发挥市场机制的作用，又履行政府的促进职责。

2. 坚持扩大就业与提高就业质量并重

一方面要千方百计扩大就业容量，创造更多就业岗位，缓解总量压力；另一方面要注重提高就业质量，改善劳动条件，提高劳动报酬，完善社会保障，使劳动者实现体面劳动。当前我国就业工作正从单纯追求数量扩张，转向数量与质量并重、更加注重质量。

3. 坚持突出重点与统筹兼顾相结合

就业工作要突出重点群体，优先做好高校毕业生、农民工、就业困难人员、退役军人等重点群体就业工作；同时要统筹城乡就业、统筹区域就业，促进各类劳动者平等就业、充分就业。

4. 坚持改革创新与完善制度相结合

深化就业体制机制改革，消除影响平等就业的不合理限制和就业歧视；创新就业服务方式方法，运用互联网、大数据等现代信息技术提高就业服务的精准性和有效性。

5. 坚持底线思维，防范规模性失业风险

就业工作要坚持底线思维，密切监测就业形势变化，完善失业预警机制，做好应对预案，坚决防止发生规模性失业风险。这是就业工作的基本要求，也是维护社会稳定的重要保障。

6. 坚持系统观念，统筹多方资源

就业工作涉及经济、社会、教育、科技等多个领域，要坚持系统观念，加强部门协同，统筹政策资源、资金资源、服务资源，形成促进就业的强大合力。就业指导师在实际工作中也要善于整合各方资源，为求职者提供综合性服务。

八、就业指导工作必须掌握的几个重要概念辨析

1. “充分就业”与“高质量充分就业”

“充分就业”是经济学概念，指有劳动能力且愿意工作的人都能够就业的状态，不排除存在一定的摩擦性失业和结构性失业。“高质量充分就业”则是在充分就业基础上的更高要求，强调就业数量与就业质量的统一，是我国新时代就业工作的新定位。

2. “就业优先”与“就业第一”

“就业优先”是指在政策制定和发展规划中优先考虑就业因素，是战略层面的规范表述；“就业第一”不是规范的政策表述，考试中要注意区分，不要把二者混为一谈。

3. “积极的就业政策”与“就业优先政策”

“积极的就业政策”是我国长期实行的就业政策总称，强调政府主动作为、积极促进就业；“就业优先政策”是实施就业优先战略的具体政策安排，强调在宏观政策体系中把就业放在优先位置。二者一脉相承，“就业优先政策”是“积极的就业政策”在新时代的深化和发展。

4. “体面劳动”与“高质量就业”

“体面劳动”是国际劳工组织提出的概念，指在自由、公平、安全和有尊严的条件下，男女都能获得的生产性劳动，强调权利保护、社会保障和社会对话。“高质量就业”与之内涵相通，都强调就业的质量维度。我国促进高质量充分就业，与国际社会倡导的体面劳动理念是一致的。

九、从就业政治理论看就业指导师的职责定位

1. 就业指导师是就业优先战略的基层执行者

就业优先战略和积极的就业政策，最终要通过基层就业服务落地。就业指导师身处就业服务一线，直接面向求职者和用人单位，是政策宣传者、服务提供者、权益维护者。掌握就业相关政治理论，有助于就业指导师在工作中准确宣传政策、正确引导预期。

2. 坚持以人民为中心的工作导向

以人民为中心的发展思想，要求就业指导工作把求职者的利益放在首位：尊重求职者意愿，保护求职者隐私，杜绝就业歧视，帮助每一位求职者通过劳动实现自身发展。这是就业指导师职业道德的根本要求。

3. 服务高质量充分就业大局

就业指导师的日常工作——职业指导、岗位推荐、技能培训推介、创业指导、就业援助——正是促进高质量充分就业的具体实践。特别是做好高校毕业生、就业困难人员等重点群体的指导服务，就是在为实现“更充分、更高质量”的就业目标作贡献。

4. 政策理论考试的复习方法

本章内容以记忆理解为主。复习时建议：先抓“地位表述”（民生之本、最大民生、六稳六保之首），再抓“战略主线”（就业优先战略→高质量充分就业），然后按八大主题串记重要论述，最后用口诀巩固。做题时注意区分规范表述与非规范表述，这是本章最常见的命题陷阱。

【必背要点】

1. 就业是民生之本、最大的民生；“六稳”之首是稳就业，“六保”之首是保居民就业。

2. 实施就业优先战略：把促进就业作为经济社会发展的优先目标，放在更加突出的位置；在制定宏观经济政策和发展规划时优先考虑就业因素。

3. 促进高质量充分就业是新时代新征程就业工作的新定位、新使命。

4. 高质量充分就业内涵：“更充分”（就业规模扩大、结构优化、机会公平）+“更高质量”（就业质量提升、劳动报酬增长、劳动关系和谐）。

5. 高质量充分就业五大特征：就业容量大、就业结构优、就业机会公平、就业质量高、劳动关系和谐。

一、单项选择题

1. 关于就业在我国经济社会发展中的地位，下列说法错误的是（ ）

A. 就业是民生之本

B. 就业是最大的民生

C. “六稳”之首是稳就业

D. “六保”之首是保市场主体

参考答案：D

解析：“六保”之首是保居民就业，不是保市场主体。就业是民生之本、最大的民生，“六稳”之首是稳就业、“六保”之首是保居民就业。

2. 实施就业优先战略的实质是（ ）

A. 所有政策都只为促进就业服务

B. 把促进就业作为经济社会发展的优先目标，在制定宏观经济政策和发展规划时优先考虑就业因素

C. 政府包办一切就业

D. 优先解决城镇居民就业

参考答案：B

解析：就业优先不是指所有政策都只为就业服务，而是指在制定宏观经济政策和经济社会发展规划时，把扩大就业、稳定就业作为优先考虑的因素。

解析：公开表述明确，促进高质量充分就业是新时代新征程就业工作的新定位、新使命。
