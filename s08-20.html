【知识精讲】

一、求职能力概述

（一）求职能力的构成

求职能力是指劳动者为获得就业岗位而应具备的综合能力，主要包括：

1. 自我认知能力：了解自己的兴趣、性格、能力、价值观，明确适合的职业方向。

2. 信息搜集能力：通过多种渠道搜集招聘信息、行业信息、企业信息，并能辨别真伪。

3. 简历制作能力：制作针对性强、重点突出的求职简历。

4. 面试应答能力：在面试中清晰表达、从容应答，展示自身优势。

5. 沟通表达能力：口头和书面表达清楚得体，善于倾听和回应。

6. 心理调适能力：正确面对求职挫折，保持积极心态，合理调适压力。

（二）求职能力实训的意义

1. 对求职者：提升求职成功率，缩短求职周期，帮助其找到更匹配的岗位。

2. 对公共就业服务：提高就业服务质量，促进人岗匹配，是就业指导工作的重要抓手。

3. 对社会：降低摩擦性失业，促进人力资源合理配置。

（三）实训的主要对象

高校毕业生、失业人员、农民工、就业困难人员等有求职需求的劳动者。针对不同对象，实训内容各有侧重：高校毕业生侧重面试技巧和职业形象，失业人员侧重简历优化和心理调适，农民工侧重基本求职规范和权益保护常识。

（四）求职能力实训的基本原则

1. 以学员为中心：从学员的实际需求出发，而不是从讲师想讲什么出发。

2. 理论够用、突出实操：知识讲解精炼，把时间留给模拟演练。

3. 分层分类：根据学员的学历、经历、求职目标分班分层，提高针对性。

4. 即学即用：培训内容与真实求职场景紧密结合，学完就能用。

5. 跟踪服务：培训结束不是服务的结束，要跟踪学员的求职结果。

二、简历制作

（一）简历的类型

1. 时间型简历：按时间倒序排列教育经历和工作经历，突出职业发展的连续性。适合工作经历丰富、职业发展连贯的求职者，是最常用的类型。

2. 功能型简历：按技能、能力分类组织内容，突出个人能力和特长，淡化时间顺序。适合工作经历较少、转行或有职业空窗期的求职者。

3. 混合型简历：兼具时间型和功能型的特点，先展示核心技能，再按时间列出经历。适合大多数求职者。

（二）简历的结构要素

一份完整的简历通常包括：

1. 基本信息：姓名、性别、联系电话、电子邮箱、求职意向城市等。注意保护隐私，身份证号、家庭住址等敏感信息不必写。

2. 求职意向：明确应聘岗位，可附简短的职业目标说明，做到"一岗一简历"。

3. 教育背景：按时间倒序列出学校、专业、学历，高校毕业生可列出主修课程、获奖情况。

4. 工作（实习）经历：按时间倒序列出单位、岗位、任职时间、工作内容和业绩。这是简历的核心部分，要用数据和事实说话。

5. 技能证书：职业资格证书、语言能力、计算机水平等与应聘岗位相关的内容。

6. 自我评价：简明扼要，突出与岗位匹配的优点，避免空洞的套话。

（三）STAR法则

STAR法则是描述工作经历的经典方法，包括四个要素：

1. S（Situation）情境：当时面临什么样的背景和任务环境。

2. T（Task）任务：你承担的具体任务和目标是什么。

3. A（Action）行动：你采取了哪些具体行动、运用了什么方法。

4. R（Result）结果：取得了什么样的成果，最好用数据量化。

示例："在校期间担任社团宣传部长（情境），负责招新宣传工作（任务），设计制作系列海报并运营公众号推文（行动），招新人数同比增长40%（结果）。"考试中常要求用STAR法则改写一段经历描述，要掌握四个字母的含义和顺序。

（四）简历制作要点

1. 一页纸原则：内容精炼，篇幅一般控制在一页，突出重点。

2. 针对性：根据应聘岗位调整内容，突出与岗位匹配的经历和技能。

3. 关键词：使用招聘信息中的关键词，便于通过筛选。

4. 数据量化：用数字说明业绩，如"销售额增长30%""服务客户200余人"。

5. 真实准确：不夸大、不造假，时间、职务等信息真实可查。

6. 格式规范：排版整洁、字体统一、无错别字，照片端庄得体。

（六）简历的投递与跟进

1. 投递渠道：招聘网站、企业官网、招聘会现场、内部推荐等。注意通过正规渠道投递，防范虚假招聘。

2. 投递时机：心仪岗位尽早投递；招聘会现场投递可附上简短的自我介绍。

3. 跟进：投递后一周左右可通过电话或邮件礼貌询问进展；收到面试通知后及时确认时间地点。

4. 简历管理：建立求职台账，记录投递企业、岗位、时间、反馈，避免遗漏和重复投递。

（七）简历制作的常见误区

1. 信息造假：虚构学历、工作经历，一旦查实直接淘汰，并影响个人信用。

2. 内容冗长：事无巨细，重点不突出，招聘者难以快速抓住要点。

3. 千篇一律：一份简历投所有岗位，缺乏针对性。

4. 错别字和语病：细节失分，给人不认真的印象。

5. 联系方式错误或缺失：导致用人单位无法联系，错失机会。

6. 自我评价空洞：通篇"吃苦耐劳、团结协作"，没有实质内容。

7. 照片不规范：使用生活照、大头贴，影响专业形象。

三、面试技巧

（一）面试的主要类型

1. 结构化面试：有固定的问题清单和评分标准，对每位候选人问相同或类似问题，公平性和可比性强。公共部门招聘常用此种方式。

2. 非结构化面试：没有固定提纲，面试官根据谈话情况自由提问，气氛较轻松，但主观性较强。

3. 情景模拟面试：设置与工作相关的情景，要求候选人现场处理，考察实际工作能力。

4. 无领导小组讨论：一组候选人围绕给定议题自由讨论，面试官观察其组织协调、沟通表达、团队合作等能力。不指定领导，考察的是自然涌现的领导力和协作精神。

5. 电话/视频面试：通过电话或网络进行，常用作初筛，也用于异地面试。

（二）面试前的准备

1. 了解企业：搜集企业基本情况、主营业务、企业文化，做到心中有数。

2. 熟悉简历：对简历上的每一段经历都能展开说明，前后一致。

3. 准备自我介绍：1—3分钟版本，突出与岗位匹配的亮点。

4. 预想常见问题：提前准备高频问题的回答思路，但不要死记硬背。

5. 准备提问环节：准备1—2个有质量的问题，如岗位发展空间、团队情况等，避免问薪资福利等敏感问题过早。

6. 物品与行程：带好简历、证书复印件，提前规划路线，提前到达。

（三）常见问题的应答技巧

1. "请做一下自我介绍"：按"基本情况＋核心优势＋应聘动机"结构，简明扼要，突出匹配度。

2. "你的优缺点是什么"：优点结合实例说明；缺点谈真实但不致命的方面，并说明改进措施。

3. "为什么选择我们公司"：结合企业特点和自身职业规划作答，体现诚意和了解。

4. "你的职业规划是什么"：短期目标与长期目标结合，与应聘岗位的发展方向一致。

5. "期望薪资是多少"：提前了解市场行情，给出合理区间，表达可协商的态度。

6. "你还有什么问题要问"：问岗位职责、发展空间等实质问题，不问已公开的信息。

应答通用原则：真诚不做作，简洁有条理，紧扣岗位需求，多用实例和数据，避免背诵腔。

（四）无领导小组讨论的应对技巧

1. 了解规则：明确讨论时间、发言规则，快速进入角色。

2. 争取首发言：在讨论开始时争取首先发言，提出框架性意见，奠定基础。

3. 把握角色：可承担组织者、计时者、总结者等角色，展现组织协调能力；即使不做组织者，也要积极贡献观点。

4. 倾听与回应：认真倾听他人发言，适时回应和补充，不打断、不争吵。

5. 推动共识：在意见分歧时，归纳各方观点，推动小组达成一致。

6. 注意时间：提醒小组注意时间分配，确保按时完成讨论。

（五）压力面试的应对

压力面试是面试官通过连续追问、质疑甚至否定，考察候选人抗压能力和应变能力的面试方式。应对要点：

1. 识别意图：明白这是考察抗压能力的手段，不是针对个人，保持冷静。

2. 不卑不亢：坚持自己的观点，有理有据地回应，不轻易被带偏，也不与面试官争执。

3. 逻辑清晰：回答问题条理分明，即使被打断也要把核心观点表达完整。

4. 适度幽默：用得体的幽默化解紧张气氛，展现从容心态。

（六）面试禁忌

1. 迟到：这是大忌，务必提前到达。

2. 夸夸其谈或过分谦虚：前者不踏实，后者不自信，都不可取。

3. 贬低 former 单位或上司：显得格局小、难相处。

4. 打断面试官：不礼貌，要耐心倾听。

5. 频繁看手机：心不在焉的表现，面试时手机调至静音。

6. 虚假回答：经不起追问，一旦识破直接淘汰。

四、求职礼仪

（一）着装礼仪

1. 整洁得体：服装干净整洁，符合岗位和行业特点。一般岗位以简洁大方的职业装为宜。

2. 不宜事项：不穿奇装异服，不佩戴过多饰品，香水宜淡不宜浓。

（二）仪态礼仪

1. 敲门：轻敲两三下，得到允许后再进入。

2. 问候：面带微笑，主动问好，称呼得体。

3. 握手：力度适中，时间简短，注视对方。

4. 坐姿：坐姿端正，不跷二郎腿，不抖腿。

5. 眼神：与面试官保持适度的眼神交流，不躲闪、不直视过久。

6. 告别：起身道谢，带走个人物品，轻轻关门。

（三）沟通礼仪

1. 倾听：耐心听完问题再回答，不抢话。

2. 表达：语速适中，吐字清晰，条理分明。

3. 称谓：使用"您""贵公司"等敬语，称呼面试官可用"面试官""老师"。

4. 肢体语言：自然放松，避免小动作。

（四）电话面试礼仪

1. 环境安静：选择安静、信号好的环境接听。

2. 准备充分：手边放好简历、纸笔，提前了解企业。

3. 语气热情：声音洪亮、语气积极，弥补看不到表情的不足。

4. 记录要点：记下面试官的问题和关键信息。

（五）视频面试礼仪

1. 设备调试：提前测试摄像头、麦克风、网络。

2. 背景整洁：选择干净整洁的背景，光线充足， face 光源。

3. 着装正式：按现场面试标准着装，不可"上正式下随意"。

4. 目视镜头：发言时注视摄像头，模拟眼神交流。

5. 防止干扰：关闭无关软件通知，告知家人避免打扰。

（六）面试后的礼仪

1. 感谢信：面试后24小时内发送感谢信，重申应聘意愿，简短回顾面试亮点。

2. 耐心等待：按约定的时间等待通知，不频繁催问。

3. 无论结果：收到录用或拒绝通知，都要礼貌回应；被拒绝时可请教改进建议。

五、求职能力实训课程的设计与组织

（一）需求分析

课程设计的第一步是需求分析，了解学员的求职现状、能力短板和培训期望。方法包括问卷调查、访谈、观察等。需求分析要回答三个问题：学员缺什么（培训需求）、想学什么（学习意愿）、能学什么（接受能力）。

（二）培训目标设定

目标要具体、可衡量，符合SMART原则：具体的（Specific）、可衡量的（Measurable）、可实现的（Achievable）、相关的（Relevant）、有时限的（Time-bound）。例如："培训结束后，学员能独立制作一份针对性强的一页纸简历，并在模拟面试中完整运用STAR法则作答。"

（三）培训内容设计

按模块设计课程内容，常见模块包括：

1. 求职准备模块：自我认知、职业定位、信息搜集。

2. 简历制作模块：简历类型、结构要素、STAR法则、误区纠正。

3. 面试技巧模块：面试类型、面试准备、应答技巧、无领导小组讨论。

4. 求职礼仪模块：着装仪态、沟通礼仪、电话视频面试礼仪。

5. 心理调适模块：压力管理、挫折应对、积极心态。

内容设计要求：突出实操，理论够用即可；案例本土化，多用真实招聘案例；难度循序渐进。

（四）教学方法的选择

1. 讲授法：讲解知识要点，适合概念、流程类内容，宜精讲。

2. 案例分析法：用真实简历、面试案例进行分析讨论。

3. 角色扮演法：学员分组扮演求职者和面试官，体验双向视角。

4. 模拟面试：全真模拟面试场景，导师现场点评，是实训的核心环节。

5. 小组讨论法：围绕求职中的问题展开讨论，集思广益。

6. 示范观摩法：播放优秀面试视频，或请成功求职者分享经验。

教学方法选择的原则：以学员为中心，以实操为导向，多种方法配合使用。

（五）师资配备

实训师资包括就业指导人员、人力资源从业者、企业招聘负责人、创业成功人士等。师资要熟悉招聘实际，能讲、会评、善指导。

（六）组织实施流程

1. 招生宣传：明确培训对象、内容、时间地点，通过多种渠道发布招生信息。

2. 学员筛选：了解学员基本情况和求职需求，合理编班。每班人数不宜过多，以保证实训效果。

3. 开班组织：做好场地、设备、资料准备，明确培训纪律。模拟面试需要准备独立的面试室、计时器、评分表等。

4. 授课实训：按计划组织教学，突出模拟面试等实训环节。每位学员至少参加一次全真模拟面试，并获得个性化点评。

5. 考核评估：对学员的学习效果进行考核，如简历作品评审、模拟面试打分。考核结果反馈给学员本人，作为改进依据。

6. 结业跟踪：培训结束后跟踪学员求职进展，提供后续指导，形成服务闭环。建立学员求职档案，统计就业率，检验实训成效。

（七）效果评估

采用柯克帕特里克四级评估模型：

1. 反应层：学员对课程内容、师资、组织的满意度评价。

2. 学习层：学员知识、技能的提升程度，如简历质量的前后对比。

3. 行为层：学员在实际求职中是否运用所学技能。

4. 结果层：学员的求职成功率、求职周期是否改善。

四级评估层层递进，结果层是最根本的衡量标准。评估结果用于持续改进课程设计。

六、求职心理调适

（一）求职中常见的心理问题

1. 焦虑：担心找不到工作，对未知充满恐惧。

2. 自卑：因学历、经历不如人而自我否定，面试时不敢表达。

3. 急躁：期望过高、急于求成，被拒绝后情绪波动大。

4. 依赖：缺乏主见，完全依赖他人安排，逃避自主求职。

（二）心理调适的方法

1. 合理定位：根据自身条件设定切合实际的求职目标，不过高也不过低。

2. 积极归因：被拒绝后客观分析原因，把失败看作成长的机会，而不是全盘否定自己。

3. 压力管理：通过运动、倾诉、兴趣爱好等方式释放压力；掌握深呼吸、积极自我暗示等放松技巧。

4. 寻求支持：与家人朋友沟通，参加求职互助小组，必要时寻求专业心理咨询。

5. 保持节奏：制定求职计划，保持规律作息，用行动驱散焦虑。

（三）指导人员的疏导要点

1. 倾听共情：先倾听学员的困扰，表达理解，不轻易评判。

2. 认知调整：帮助学员纠正"非黑即白""以偏概全"等不合理信念。

3. 行为激活：鼓励学员从小事做起，如每天投递几份简历，用行动积累信心。

4. 及时转介：发现有严重心理问题倾向的学员，及时转介专业心理咨询机构。

【必背要点】

1. 求职能力六构成：自我认知、信息搜集、简历制作、面试应答、沟通表达、心理调适。

2. 简历三类型：时间型（倒序，适合经历丰富者）、功能型（按技能分类，适合转行、空窗期）、混合型（兼具两者）。

3. 简历六要素：基本信息、求职意向、教育背景、工作经历、技能证书、自我评价；核心是工作经历。

4. STAR法则：S情境、T任务、A行动、R结果；用于描述工作经历，面试中同样适用。

5. 简历制作六要点：一页纸、针对性、关键词、数据量化、真实准确、格式规范。

6. 简历七误区：信息造假、内容冗长、千篇一律、错别字、联系方式有误、自我评价空洞、照片不规范。

7. 面试五类型：结构化、非结构化、情景模拟、无领导小组讨论、电话/视频面试。

8. 面试准备六项：了解企业、熟悉简历、准备自我介绍、预想问题、准备提问、物品行程。

9. 应答通用原则：真诚不做作，简洁有条理，紧扣岗位需求，多用实例数据。

10. 无领导小组讨论技巧：争取首发言、把握角色、倾听回应、推动共识、注意时间。

11. 求职礼仪要点：着装整洁得体、仪态端庄、沟通有礼、电话视频各有规范、面试后24小时内发感谢信。

12. 课程设计四步：需求分析→目标设定（SMART）→内容设计（模块化）→方法选择（以实操为导向）。

13. 组织实施六流程：招生宣传→学员筛选→开班组织→授课实训→考核评估→结业跟踪；每位学员至少参加一次全真模拟面试。

14. 柯克帕特里克四级评估：反应层、学习层、行为层、结果层，层层递进，结果层最根本。

15. 实训五原则：以学员为中心、理论够用突出实操、分层分类、即学即用、跟踪服务。

16. 简历投递跟进：正规渠道投递、心仪岗位尽早投、一周左右礼貌跟进、建立求职台账防遗漏。

17. 求职心理四问题：焦虑、自卑、急躁、依赖；调适五法：合理定位、积极归因、压力管理、寻求支持、保持节奏；严重者转介专业机构。

【记忆口诀】

口诀一：求职能力六构成

"认知信息简历三，面试沟通心理全；六种能力都练好，求职路上底气添。"

说明：自我认知、信息搜集、简历制作、面试应答、沟通表达、心理调适——"三"指前三项基础能力，"全"指后三项综合能力。

口诀二：STAR法则

"S情T任A行动，R结果要量化；简历面试都能用，经历描述顶呱呱。"

说明：S（Situation）情境、T（Task）任务、A（Action）行动、R（Result）结果。注意顺序不能颠倒，结果最好用数据量化。

口诀三：简历制作要点与误区

"一页针对关键词，数据真实格式端；七大误区要避开：造假冗长错字连。"

说明：要点——一页纸、针对性、关键词、数据量化、真实准确、格式规范；误区——信息造假、内容冗长、千篇一律、错别字、联系方式有误、自我评价空洞、照片不规范。

口诀四：面试准备与礼仪

"面试准备六件事：企业简历自我介绍备，问题提问行程随；礼仪着装仪态沟通全，电话视频各守规；感谢信在廿四内，耐心等待有风度。"

说明：准备六项——了解企业、熟悉简历、准备自我介绍、预想问题、准备提问、物品行程；面试后24小时内发感谢信。

口诀五：课程设计与评估

"设计四步：需求目标内容法；实施六环：招生筛选开班授考跟；评估四级：反应学习行为果，层层递进入结果。"

说明：课程设计——需求分析、目标设定、内容设计、方法选择；组织实施——招生宣传、学员筛选、开班组织、授课实训、考核评估、结业跟踪；四级评估——反应层、学习层、行为层、结果层。

【章后真题/练习】

说明：经核查，本章暂未收录到确有把握的就业指导师考试历年真题。以下为模拟练习题（非真题），供自我检测使用。

一、单项选择题

1. STAR法则中，"A"代表（ ）。

A. 情境

B. 任务

C. 行动

D. 结果

参考答案：C。解析：S是情境（Situation）、T是任务（Task）、A是行动（Action）、R是结果（Result），顺序不能颠倒。

2. 按时间倒序列出教育经历和工作经历，突出职业发展连续性的简历类型是（ ）。

A. 时间型简历

B. 功能型简历

C. 混合型简历

D. 创意型简历

参考答案：A。解析：时间型简历按时间倒序排列，适合经历丰富、发展连贯者；功能型按技能分类，适合转行或有空窗期者。

3. 面试后发送感谢信的合适时间是（ ）。

A. 面试后一周内

B. 面试后24小时内

C. 面试后一个月内

D. 收到录用通知后

参考答案：B。解析：面试后24小时内发送感谢信，重申应聘意愿，是规范的面试后礼仪。

4. 柯克帕特里克四级评估模型中，最根本的衡量标准是（ ）。

A. 反应层

B. 学习层

C. 行为层

D. 结果层

参考答案：D。解析：四级评估层层递进，结果层（求职成功率、求职周期改善）是最根本的标准。

5. 一组候选人围绕议题自由讨论、不指定领导的面试形式是（ ）。

A. 结构化面试

B. 非结构化面试

C. 无领导小组讨论

D. 情景模拟面试

参考答案：C。解析：无领导小组讨论不指定领导，考察自然涌现的领导力和团队协作能力。

6. 下列关于压力面试的应对，正确的是（ ）。

A. 与面试官争辩以证明自己正确

B. 保持冷静，不卑不亢，逻辑清晰地回应

C. 尽快结束面试，避免尴尬

D. 顺着面试官的否定全盘推翻自己的观点

参考答案：B。解析：压力面试考察抗压能力和应变能力，应对要点是识别意图、保持冷静、不卑不亢、逻辑清晰。

7. 培训目标"培训结束后，学员能独立制作一份针对性强的一页纸简历"体现了SMART原则中的（ ）。

A. 具体的、可衡量的

B. 可实现的

C. 相关的

D. 有时限的

参考答案：A。解析："独立制作一份针对性强的一页纸简历"具体明确、可检验，体现具体的（Specific）和可衡量的（Measurable）。

二、多项选择题

1. 求职能力实训课程设计的内容模块包括（ ）。

A. 求职准备模块

B. 简历制作模块

C. 面试技巧模块

D. 求职礼仪模块

参考答案：ABCD。解析：常见模块还包括心理调适模块；内容设计要求突出实操、模块化。

2. 下列属于简历制作误区的有（ ）。

A. 信息造假

B. 内容冗长、重点不突出

C. 一份简历投所有岗位

D. 简历中有错别字

参考答案：ABCD。解析：四项均为常见误区；制作要点是针对性（一岗一简历）、精炼、规范、真实。

三、简答题

1. 简述STAR法则的内容及其在简历和面试中的应用。

参考答案：STAR包括S情境、T任务、A行动、R结果。在简历中用于描述工作经历，使经历具体可信，结果用数据量化；在面试中用于回答行为类问题，按"情境—任务—行动—结果"结构组织答案，条理清晰、有说服力。

2. 简述求职能力实训课程组织实施的基本流程。

参考答案：招生宣传→学员筛选→开班组织→授课实训→考核评估→结业跟踪。核心是授课实训环节（突出模拟面试）；结业后跟踪学员求职进展，提供后续指导，形成服务闭环；用四级评估检验效果并持续改进。
