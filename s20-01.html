Fromkin · 中国未来的市场

前言

**先说清一个问题：中国还有多大的市场**

这些年，无论在国内的饭桌上，还是在海外的会议室里，总有人把同一个问题换着说法问出来：中国市场还行不行？问的人各有各的处境。做外贸的，感觉订单不如从前好拿；开小店的，觉得客人比过去挑剔、也比过去会算账；刚毕业的年轻人，一边刷着手机下单一边抱怨工资涨得慢；跨国公司的高管则更直接，他们要向董事会回答的是：中国还值不值得继续投。

这本书想先把这个问题拆开。因为“中国还有多大的市场”，其实是三个不同的问题：市场还大不大？市场还在不在长？市场还是不是原来那个市场？三个问题的答案并不一样，有的甚至正好相反。把它们混在一起谈，只会越谈越糊涂。先说清这一个问题，后面的十五章才有着落。

先把大盘摆出来

判断一个市场，先看体量。按国家统计局《2024年国民经济和社会发展统计公报》，2024年中国国内生产总值134.9万亿元，增长5.0%，人均GDP达到95749元；年末全国人口140828万人。这组数字摆在一起的意思是：中国有一个以十四亿人为底座、年度经济总量超过一百万亿元的超大规模市场，这在人类商业史上没有先例——不是没有过人口大国，也不是没有过富裕国家，而是人口之多与购买力之实第一次在同一个国家里叠加。

再看消费这一头。2024年社会消费品零售总额48.3万亿元，增长3.5%（国家统计局统计公报口径）；最终消费支出拉动国内生产总值增长2.2个百分点。48.3万亿元是什么概念？它意味着平均每天有超过一千亿元的商品和餐饮消费在这个国家里发生（分析推演：这是把年度总额摊到每一天的算法，只是为了给读者一个直观的量感）。与此同时，全国网上零售额2024年达到15.5万亿元（国家统计局），快递业务量全年1750.8亿件（国家邮政局《2024年邮政行业发展统计公报》）——平均每个中国人一年收一百多个包裹。货物进出口总值43.85万亿元（海关总署），中国是150多个国家和地区的主要贸易伙伴。这个大盘，就是讨论一切变化的起点：变化再大，也是在这个量级上发生的。

还要看供给这一头，因为市场从来是买卖双方的事。2024年末，全国登记在册经营主体1.89亿户（市场监管总局），2024年一年新设经营主体2737万户。也就是说，这片土地上平均不到八个人就摊着一户登记在册的经营主体——卖方的密度同样是世界罕见的。市场的一边是十四亿消费者，另一边是近两亿经营者，两边都极其拥挤，这个基本格局决定了中国未来市场的许多特征：机会永远在，利润永远薄，变化永远快。

最后看时间维度。大盘不是静止的相片，而是仍在生长的活物——只是生长的部位变了。理解这一点，可以用一个朴素的比喻：过去的中国市场像一个少年，骨骼和体重一起往上蹿，什么衣服都要年年换大一号；现在的中国市场更像一个步入中年的壮汉，体重变化不大，但肌肉与脂肪的比例在重塑，力量和耐力的分布与从前完全不同。用少年时代的食谱去喂壮汉，或者用壮汉的体型去否定他的力量，都是误判。读这本书，希望读者时常想起这个比喻：我们谈论的不是市场的青春告别，而是市场的成年礼。

再看几个热点切面

只看总量容易犯困，再切几个行业的横截面，市场立刻生动起来。

汽车是最典型的样本。2024年全国汽车产销分别完成3128.2万辆和3143.6万辆，其中新能源汽车产销1288.8万辆和1286.6万辆，新能源新车销量占汽车新车总销量的40.9%（中国汽车工业协会）。十年前还被当作“未来产业”的新能源车，如今每卖出十辆新车就有四辆是它；与此同时，燃油车的份额在收缩，合资品牌的定价体系被打乱，整个行业的利润在重新洗牌。一个行业之内，兴衰可以同时发生——这就是结构变迁最直观的样子。

旅游是另一个横截面。2024年国内出游56.15亿人次，国内游客出游总花费5.75万亿元，入境游客13190万人次（文化和旅游部）。出游人次相当于全国人口人均出游四次——中国人正把越来越多的时间和钱花在“移动”和“体验”上，本书第十二章会细算这笔账。

外贸的横截面同样值得摆出来：2024年跨境电商进出口2.63万亿元，增长10.8%，自主品牌占出口的比重达到21.8%，电动汽车出口首次突破200万辆（海关总署）。这些数字背后是中国与世界市场关系的位移：中国不再只是替世界加工，也在把自己的品牌、渠道和生活方式卖给世界。

还有两个不容易被消费者直接看见、却决定市场上限的切面。一是创新投入：2024年全社会研究与试验发展经费36326.8亿元，增长8.9%，投入强度达到2.69%（国家统计局科技经费公报口径）。研发投入决定的是未来货架上有什么新东西可卖。二是数字底座：2023年我国数字经济规模53.9万亿元（中国信通院《中国数字经济发展研究报告》），数字经济早已不是一个“行业”，而是几乎所有行业共同的水电煤。这些切面合起来，勾勒出的不是一个平面的市场，而是一台内部转速各不相同的机器。

三个常见的误读

把大盘摆出来，是为了避开三个流行的误读。

第一个误读，是把增速当体量。前些年市场习惯了高速增长，许多行业的记忆里都存着“每年涨百分之十几”的年代，于是增速一旦回到个位数，就有人断言“市场不行了”。但基数不同，同样的增速对应的增量完全不同：在一个48.3万亿元的零售大盘上增长3.5%，一年的增量也超过一万亿元（分析推演：按公报口径的增速与总量粗算）。增量本身仍然巨大，只是它不再平均地落到每个行业、每个商家头上，而是越来越集中地流向少数品类和少数玩家。难受的是分配，不是总量。这本书后面会反复回到这个区分。

第二个误读，是把自己的生意当成整个市场。房地产下行是真事：2024年新建商品房销售面积下降12.9%，销售额下降17.1%（国家统计局）。但就在同一年，国内出游达到56.15亿人次、游客出游总花费5.75万亿元（文化和旅游部），服务零售额增长6.2%，快于商品零售（国家统计局）。钱没有消失，钱在搬家：从买房搬向出游，从囤货搬向体验，从耐用品搬向服务。只盯着一个蓄水池看，会得出“水干了”的结论；站到全流域看，结论是水改道了。

第三个误读，是以为中国市场是一个市场。它从来不是。2024年城镇居民人均可支配收入54188元，农村居民23119元，城乡比约2.34（国家统计局）；收入五等份里，低收入组人均9542元，高收入组98809元（国家统计局）。这几个数字说明：所谓“中国消费”，是好几个消费能力相差数倍、消费习惯迥然不同的人群，恰好生活在同一张地图上。一线城市在讨论情绪价值和一人食，县城在讨论婚房和金价，乡村在讨论农资和孩子的网课——用任何一个群体的体感去概括“中国市场”，都会错得离谱。未来市场的机会，恰恰藏在这种参差里。

换个问法：谁的市场在变大，谁的在变小

“中国还有多大的市场”其实还藏着一个更锋利的问法：谁的市场在变大，谁的市场在变小？因为从总量上看，这个大盘的内部正在经历剧烈的此消彼长。

城乡之间就在换位。2024年城镇消费品零售额417813亿元，乡村消费品零售额65531亿元（国家统计局）；乡村的盘子只有城镇的零头，增速却是4.3%，快于城镇。基数小、增速高、人口还在回流——乡村和县城这块市场，是全书第七章的主角。行业之间的换位更明显：服务零售额2024年增长6.2%，明显快于商品零售（国家统计局）；餐饮收入56180亿元，而商品零售427165亿元——人们花在“吃一顿好的”和“被人服务一次”上的钱，正在系统性地跑赢花在“多买一件东西”上的钱。品类之间的换位同样如此，前面提到的新能源车之于燃油车，只是其中最醒目的一例。

还有一层换位发生在国界两侧：2024年我国对共建“一带一路”国家进出口占进出口总额的比重首次超过50%（海关总署）。这句话的含意是，中国与世界做买卖的重心，正在从传统的发达经济体市场，向更广阔的新兴市场移动；未来中国企业的增量订单，越来越多地要去这些地方找，中国市场对世界的重要性，也越来越多地体现在这些地方的消费者身上。

把这些换位叠在一起，就能明白为什么“总量温和、个体剧烈”是今后很多年的常态：你的市场在不在长，取决于你站在消长的哪一边。看不清自己位置的人，会拿大盘的平均数安慰或吓唬自己；看得清的人，会先问一句：我这块细分市场，属于长的那半，还是短的那半？

这本书的看法与看法的方法

先把结论放在前面，后面十五章都是论证。这个结论是：中国市场正在从“增量市场”切换为“总量巨大、结构剧变”的市场。它的总量在可见的将来仍将是世界最大之列，但增长的方式变了——过去靠人口增加、收入普涨、水涨船高；今后靠结构迁移、品类更替、效率重组。换句话说，未来的市场机会不再来自“人更多、钱更多”这条直线，而来自“人变了、钱换地方花了、买卖的方式变了”这些弯道。这是对未来方向的判断，属于分析推演，它的成立与否，读者可以拿后面各章的证据逐一检验。

一张简表：把大盘钉在墙上

为方便读者在后面各章随时对照，这里把全书反复用到的2024年关键锚点集中列一张简表（除注明外均为国家统计局口径）：

| 指标 | 2024年数值 |

|---|---|

| 国内生产总值 | 134.9万亿元，增长5.0% |

| 人均GDP | 95749元 |

| 年末总人口 | 140828万人 |

| 社会消费品零售总额 | 48.3万亿元，增长3.5% |

| 全国网上零售额 | 15.5万亿元 |

| 居民人均可支配收入 | 41314元 |

| 居民人均消费支出 | 28227元 |

| 登记在册经营主体 | 1.89亿户 |

| 快递业务量 | 1750.8亿件（国家邮政局） |

| 货物进出口总值 | 43.85万亿元（海关总署） |

| 国内出游花费 | 5.75万亿元（文化和旅游部） |

| 新能源汽车销量 | 1286.6万辆（中国汽车工业协会） |

这张表就是这本书的“零公里标”。后面各章谈到任何细分市场的冷热，都可以回到这张表前核对：是在大盘之上起舞，还是在逆大盘而动。需要提醒的是，表里都是2024年的时点数据，它们描述的是市场的“现在时”；至于“将来时”，书里凡出现方向性说法，都标着“分析推演”四个字——那是作者基于事实作出的判断，读者尽可赞同，也尽可保留。

方法上，这本书守三条纪律。第一，数字只用公开统计口径，并注明年份和来源；查不到可靠口径的——比如某些热门赛道的“市场规模”——宁可定性描述，也不引用来历不明的预测数字。第二，凡是涉及未来的判断，一律标明“分析推演”，与已经发生的事实分开摆放，不把猜测写成新闻。第三，尽量不用“消费升级”或“消费降级”这种一锅烩的词，而是具体到人群、品类和场景：谁的钱、买什么、在哪里买、为什么买。

全书的安排也由此而来。前三章先打地基：市场从哪里来（第一章）、人还剩多少且变成什么样（第二章）、钱从哪里来又如何分配（第三章）。接着用八章分人群、分场景看市场的新版图：消费分层、银发、年轻人、下沉市场、数字市场、智能市场、绿色市场、健康市场、文旅市场。最后三章谈三个“大件”的去向：住房、金融与中国和世界市场之间的买卖。结语部分会把2035年的几幅图景集中摆出来，全部标明是推演，并附一份风险清单。

阅读时不必拘泥于顺序：关心全局的人从前言读到结语，关心具体行当的人完全可以先翻到自己那一章，再回头补地基。各章之间留了彼此呼应的线索，但每章都自成一篇，单独抽出来读也不会缺上下文——这一点，是作者写作时特意留意的。

也要提前向读者交代这本书的边界。它不提供选股建议，不预测具体某个行业哪一年达到多少规模，不替任何企业站台。它能提供的，是一套看中国市场的坐标系：底座是人，燃料是收入，河道是渠道与技术，闸门是制度与政策。坐标系搭好了，读者尽可以用它去丈量自己关心的那一小块市场——无论你是在县城开店、在平台上卖货、在工厂里排产，还是只是在替自己的家庭做一份长期的消费和储蓄安排。坐标系的用处不在于替你下结论，而在于当新闻和情绪轮番轰炸时，你手里有一把不随风摇摆的尺子。

为什么偏偏在现在谈这个问题

因为有三个转段同时发生，叠在一起，才让“市场”这个老话题变得陌生起来。

第一个转段是需求的转段。住房这个超级蓄水池的水位在下降（第十三章），汽车在从燃油向电动换代（第十章），手机等耐用消费品早已进入换机时代——支撑了过去二十年消费扩张的几个大件，先后从增量逻辑切换到存量逻辑。第二个转段是技术的转段。人工智能正在从实验室走进终端、车间和服务现场，它会创造全新的需求品类，也会改写旧品类的成本结构（第九章）；与十多年前移动互联网的那一波相比，这一波技术变迁更深地嵌入生产端，影响更慢、也更持久（分析推演）。第三个转段是人的转段。人口总量见顶、老龄化加深、家庭变小（第二章），意味着消费者本身在变：年龄结构、家庭结构、地域分布，没有一样与十年前相同。

三个转段单独看，每一个都有成熟的讨论；合在一起看，结论只有一个：中国市场已经不能再用过去的经验公式外推。企业按旧地图找新大陆，会系统性地找错地方；家庭按旧预期做大宗消费决策，也可能系统性地踩错节奏。这本书写作的目的，就是想在三个转段的交叉点上，把新地图的大致轮廓描出来——不是精密测绘，做不到，也不必；先有轮廓，细节可以各自补测。

还要说明这本书的立场：它既不是唱多，也不是唱衰。唱多者爱引用总量，唱衰者爱引用体感，本书试图证明的是，总量与体感可以同时为真——总量在高位运行，体感却因为结构剧变而普遍承压。把两件事同时说清，比站队更有用。

最后，给四种读者各留一句使用说明。做企业的人，请重点读分人群、分品类的那几章，地图的价值在于告诉你增量在哪条街上；做投资的人，请克制把书中任何方向性判断直接翻译成买卖信号的冲动，本书说的是十年尺度的地形，不是下个季度的天气；做具体公共服务工作的人，第二、三章和银发、下沉两章也许最对胃口，那里谈的安全网、县域和老人，都是服务落地的现场；普通家庭的读者，则不妨把这本书当作一份家庭财务的背景读物：理解收入的结构、资产的周期和消费的迁移，比追逐任何风口都更能保护自己的钱包。四种读法之外，若你还能在书里读出一点对这片土地上普通人生活的体谅，那是作者额外的收获。

中国还有多大的市场？读完全书，希望你不再满足于一个字的答案——大，或者不大——而是能接着往下说：大在哪里，变在哪里，机会在谁手里，风险又埋在哪里。这才是这个问题值得用一本书来回答的理由。
