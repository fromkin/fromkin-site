Fromkin · 劳动科学概论（第二版）

结语 劳动科学与人的全面发展：一条没有终点的路

全书十五章，我们走完了一段从"劳动是什么"到"劳动向何处去"的旅程。开篇从劳动的基本概念出发：劳动是人类特有的有目的的活动，是文明的源泉，也是个人安身立命之本。接着，我们确立了全书的两条主线——"劳动价值实现"与"人的全面发展"；梳理了理论基础——从重要论述到理论体系的五大方面与学理化路径；然后走进六大领域：劳动经济学讲价值创造，劳动关系论讲价值实现，劳动发展论讲能力提升，劳动保障论讲价值保障，劳动法治论讲价值规范，劳动教育论讲价值内化；最后，我们把六大领域连成价值链条，看两条主线在此汇合，回顾中国劳动科学的来路，眺望智能化时代的未来。

这十五章看似庞杂，其实只讲了一件事：劳动的价值如何实现，以及这一切最终为了人的全面发展。结语不做新的论述，只做三件事：回望两条主线，回望六大领域与价值链条，回望理论基础；然后展望未来，为全书收束。

回望不是重复，而是提炼。读完全书再回头看，那些散在各章的概念——劳动的二重属性、劳动关系的特征、价值实现的三层含义、全面发展的三个关键词——会第一次显现出它们之间的联系：原来它们都是两条主线在不同位置的"投影"，都是价值链条上不同环节的"注脚"。这种"原来如此"的贯通感，正是体系化阅读的回报。

一、回望两条主线：过程与归宿

先回望第一条主线"劳动价值实现"。全书讲到这里，读者应当已经看到，"实现"二字重若千钧。它包含三层含义：价值要被创造出来（劳动经济学），要被分配下去（劳动关系论、社会保障论），要被保障得住（劳动法治论）；而让这一切可持续的深层基础，是价值的内化（劳动教育论）。六大领域各有侧重，但都在回答同一个问题：劳动创造的价值，如何真正落到劳动者身上？

再回望第二条主线"人的全面发展"。它是全书的归宿：每个人的体力、智力、个性和创造能力得到自由充分的发展；人不再是生产的附属物，而是生产的目的本身。劳动发展论讲能力成长，劳动教育论讲价值认同，讲的都是这条主线；而其他四个领域，也都要接受它的检验：效率的提高是否转化为了人的发展条件？制度的完善是否让人生活得更有尊严？

两条主线的关系，全书反复论述，这里再提炼为三句话。第一句：劳动价值实现是过程，人的全面发展是归宿——过程再热闹，也要问"为了什么"。第二句：两条主线相互促进，形成螺旋上升的循环——价值实现得越充分，人发展的条件越好；人发展得越全面，创造价值的能力越强。第一章里那个进城务工青年的故事，就是这个循环的缩影：培训带来证书，证书带来收入与社保，稳定带来学习，学习带来更大的价值。每一个普通劳动者的向上流动，都是两条主线相互促进的一次验证。第三句：偏废其一都会让劳动科学走偏——只见价值不见人，会滑向技术之学；只见人不见价值，会变成空泛说教。

这两条主线，也是检验全书是否成立的标尺。读者合上书后，可以做一个检验：随便翻开一章，问两个问题——这一章讲的内容，对"劳动价值实现"贡献了什么？对"人的全面发展"贡献了什么？如果每一章都能答得上来，说明两条主线真正贯穿了全书；如果有哪一章答不上来，那正是体系需要修补的地方。把这个检验方法教给读者，比多讲一个知识点更有价值——因为它把"评判理论体系"的权力，交到了每一个读者的手里。

如果只能带走一句话，那就是：劳动科学研究"劳动"，但它的眼睛始终看着"人"——因为一切关于劳动的知识，最终都是为了让人活得更有尊严。

顺带一提，第一版其实也有一条隐含的主线，就是"人"——开篇讲劳动的概念，结尾讲"以人为本、改善劳动"。第二版的进步在于，把这条隐含的主线显性化为"人的全面发展"，又增加了一条"劳动价值实现"作为它的搭档：原来只有"方向"，现在有了"道路"；原来只有"归宿"，现在有了"过程"。两条主线相互支撑，理论体系才算真正立起来。这也是第二版与第一版最本质的区别：不是知识点的增减，而是"骨架"的重塑。

二、回望六大领域：一个相互联系的整体

再回望六大领域。它们不是六个孤岛，而是一条价值链条上的六个环节：价值创造 → 价值实现 → 价值保障 → 价值规范 → 价值内化 → 人的全面发展。

劳动经济学是起点，回答劳动如何创造价值、促进发展。没有创造，后面一切无从谈起；但创造不是目的，而是手段——它的意义在于为后面的环节提供"源头活水"。

与第一版相比，第二版的六大领域有一个明显变化：原来按"分支学科"划分的七个部分（劳动经济学、劳动法学、劳动社会学、劳动心理学、劳动管理学、劳动保护学、社会保障学），变成了按"价值链条"划分的六个领域。分支学科的划分依据是"用什么视角研究"，领域的划分依据是"在链条中处在什么位置、回答什么问题"。这个变化意味着：知识不再按"学科领地"归类，而按"功能位置"归类——同一个知识点，在第一版里属于某个学科，在第二版里属于链条的某一环。位置变了，知识的意义也就变了：它不再是一个孤立的结论，而是整体中的一个环节。这正是"体系"与"拼盘"的区别。

劳动关系论是价值实现的主场，回答劳动价值如何在组织关系中实现。从传统的劳动合同、集体协商，到新就业形态、平台用工、算法管理，这个领域直面着变化最剧烈的现实。价值能不能落到劳动者身上，首先看这个环节。

劳动发展论是第二条主线最直接的体现，回答劳动者如何实现能力提升与发展。技能的形成、职业生涯的展开、人力资源的开发，讲的都是"人"的成长。它提醒我们：劳动者不是实现价值的工具，劳动者本身的发展就是目的。

劳动保障论回答如何稳定和保障劳动价值实现。人的一生会遇到年老、疾病、失业、工伤，价值实现经不起风浪，就需要社会保障这张"安全网"接住。它讲的是"稳"字——稳住了，价值实现才是可持续的。

劳动法治论回答如何通过法治规范劳动关系。权利要有边界，争议要有说理的地方，底线要有强制力。它讲的是"正"字——正了，价值实现才有底气。

劳动教育论回答如何实现劳动价值的内在认同。它是链条上最"软"的一环，却可能是最深的一环：规则再完善，如果人不认同，也只是纸面文章；只有当尊重劳动成为社会的共识、成为人的信念，整个链条才有了灵魂。

六个环节，一个都不能少；少了任何一个，链条就会断裂：没有创造，巧妇难为无米之炊；没有实现，价值悬在空中；没有保障，风浪一来就翻船；没有规范，弱者没有底气；没有内化，制度没有灵魂。而链条的终点——人的全面发展，则是所有环节共同的方向。

还要补充一点：这条链条不是单向的"流水线"，而是有反馈的"循环"。比如，劳动教育论讲的价值内化，会反过来影响价值创造——一个认同劳动价值的社会，劳动者的积极性更高，创造的价值更多；劳动法治论讲的规范，会反过来塑造劳动关系——公正的规则让劳资双方更愿意合作，价值实现更顺畅；劳动保障论讲的兜底，会反过来促进人的发展——有安全感的人，才敢去学习、去尝试、去追求更好的生活。所以，链条的每一环既是下一环的前提，也是上一环的结果。这种相互反馈、相互促进的特性，正是"体系"区别于"拼盘"的地方：拼盘里的菜各吃各的，体系里的环节彼此成就。

不妨再用一个例子检验这条链条：平台骑手的社保难题。价值创造环节，骑手确实创造了价值（劳动经济学确认这一点）；价值实现环节，问题出现了——骑手与平台之间是什么关系？收入分配规则公平吗（劳动关系论）？价值保障环节，风险暴露了——骑手受伤谁来兜底（劳动保障论）？价值规范环节，规则缺位了——现行法律如何适用、争议找谁说理（劳动法治论）？价值内化环节，观念要跟上——社会是否真正承认骑手的劳动价值（劳动教育论）？一个议题，六个环节，环环相扣。这就是价值链条的解释力：它让复杂的问题有了清晰的"定位"，让分散的知识有了共同的"战场"。

三、回望理论基础：从重要论述到理论体系

再回望理论基础。本书的理论体系不是凭空产生的，它走的是"从重要论述到理论体系"的路。

五大梳理方面，是这条路的起点：劳动的基础性地位，确立了劳动在整个体系中的"地基"位置；就业优先导向，指明了价值实现的入手处；劳动者主体地位，把"人"请到了理论的中心；劳动关系治理，提供了连接"价值"与"人"的制度桥梁；劳动者全面发展，指明了最终的归宿。五个方面层层递进：从"劳动"到"就业"，从"劳动者"到"劳动关系"，再到"全面发展"，构成一个完整的思想链条。

学理化路径，是这条路的"施工图"：重要论述 → 梳理 → 核心概念 → 提炼 → 基本命题 → 指示 → 内在逻辑 → 转化 → 理论体系。本书不敢说自己走完了全程，但努力的方向是明确的：每一个概念都有来处，每一个判断都有依据，推论的地方标明推论（分析推演），存疑的地方承认存疑。一门学科成熟的标志，就是从"知识的堆积"走向"体系的贯通"——而贯通的前提，是诚实：诚实地标明哪些是事实、哪些是观点、哪些是推演。

细心的读者还会发现，五大方面与六大领域之间存在着呼应：劳动的基础性地位，对应着劳动经济学的"价值创造"——正因为劳动是基础，创造才值得研究；就业优先导向，对应着价值实现的"入口"——就业是价值的载体；劳动者主体地位，贯穿全部六大领域——每个领域都要把"人"放在中心；劳动关系治理，直接对应劳动关系论与劳动法治论；劳动者全面发展，则对应劳动发展论、劳动教育论，以及价值链条的终点。思想来源与知识体系在这里完成了对接：前者是"魂"，后者是"体"，魂体合一，体系才算真正立住。

这里也要坦白本书的局限。作为"概论"，它只能讲到入门的程度；作为体系化的初次尝试，它的框架未来完全可能被修正；书中凡涉及未来的判断，都已标注为"（分析推演）"，是基于现有趋势的推理，不是预言。承认局限不是谦虚，而是对读者负责——也是"从重要论述到理论体系"这条路本身要求的学风：理论体系永远在路上，永远向修正开放。

四、展望：智能化时代与劳动科学

展望未来，劳动科学正站在一个新的路口。人工智能、平台经济、远程办公，正在改写劳动的形态：机器能写文章、能开车、能看病，算法在分配任务、管理绩效，工作场所从工厂变成了屏幕。这些变化提出一连串追问：被机器替代的劳动者向何处去？平台从业者的权益如何界定？算法规则的公平性谁来监督？当"劳动"的形态都变了，劳动科学还成立吗（分析推演）？

本书的回答是：形态会变，使命不变。技术改变的是劳动的"形"——在哪里劳动、用什么工具劳动、和谁建立什么样的关系；但它改变不了劳动的"魂"——人依然要通过劳动安身立命，价值依然要在关系中实现，公平依然需要制度守护，人依然向往全面发展。只要"人"还在劳动，劳动科学就有存在的理由；只要价值实现与人的发展之间还有张力，这门学科就有要回答的问题。

更进一步说，智能化时代可能让劳动科学变得更加重要（分析推演）。当机器接管了越来越多的重复性劳动，人类劳动的独特价值——创造性、判断力、同理心、意义感——反而更加凸显，劳动发展论讲的"能力提升"就有了新的内涵：人要学什么，才能不被机器替代？当算法成为新的"管理者"，对公平、透明、可解释性的要求就比以往任何时候都迫切，劳动关系论与劳动法治论就有了新的战场：算法的规则谁来定、谁来监督？当就业形态日益灵活、职业生涯的"断裂"越来越常见，对"兜底"和"赋能"的需求就日益增长，劳动保障论讲的"安全网"就要织得更密、更韧。这些，都是劳动科学的经典议题在新时代的回响。技术越进步，"人"的议题越重要——这或许是智能化时代给劳动科学的最大启示。

当然，展望也意味着不确定。人工智能究竟会替代多少岗位、新就业形态最终会稳定在什么形态、现有的法律框架需要做多大的调整，这些今天都还没有答案（分析推演）。本书第十四章对这些问题的讨论，定位都是"提出问题、给出分析框架"，而不是"给出标准答案"。劳动科学能做的，是提供一张在不确定中思考的地图，而不是一张预言未来的藏宝图。

最后，对有志于这门学科的年轻读者说几句。劳动科学是一门"年轻的老学科"：说它老，它有两百多年的历史；说它年轻，它的理论体系至今还在完善中，六大领域的框架本身就是最新的尝试。这意味着，加入这门学科的人，有机会参与它的建设：平台经济的规则、算法管理的伦理、人工智能时代的分配正义，这些前沿议题都还没有定论（分析推演）。一门还在生长的学科，最需要的就是新人——带着问题意识来，带着田野调查来，带着跨学科的眼光来。劳动科学的未来，不在书斋里，而在车间、平台、田野和代码之中。

对读者而言，读完这本书，希望带走的不只是一堆概念和条文，而是一种看待劳动世界的眼光：看到外卖骑手时，能想到价值链条的哪一环出了问题；看到人工智能的新闻时，能想到人机之间如何分工、价值如何分配；看到自己的工资单、社保缴费单时，能想到"我处在什么样的关系中、向着什么样的未来"。这种眼光，就是劳动科学给予普通人的礼物。

不同的读者，可以把这份礼物用在不同的地方。如果你是劳动者，愿你在签合同、谈工资、缴社保时多一分清醒，在规划职业生涯时多一分从容；如果你是管理者，愿你记住"有尊严的劳动者才是最有生产力的劳动者"，把这门学科当作"成就人"的学问，而不是"使用人"的技巧；如果你是政策研究者，愿这两条主线、这条价值链条，能为你的制度设计提供一张清晰的图纸。无论你是谁，愿你在劳动中安身，在安身中立命。

劳动创造了人类本身。从石器到蒸汽机，从电力到智能设备，工具在变，形态在变，但有一件事从未改变：每一个劳动者，都值得有尊严的劳动，都有权利走向全面发展。过去两百年，劳动科学从工厂的轰鸣中诞生，在一次次社会变革中成长；今天，它又站在智能化的路口，准备回答新的问题。变的永远是问题，不变的永远是使命：让劳动更有尊严，让劳动者生活得更好。

愿这本书成为你理解劳动世界的一把钥匙，更成为你善待每一个劳动者（包括你自己）的起点。愿每一个在清晨走出家门的人，晚上归来时，都觉得这一天的劳动是值得的——这，就是劳动价值实现最朴素的样子，也就是人的全面发展最真实的起点。

最后，把一句话送给读者，也送给这门学科：两条主线，一条是路，一条是方向；六大领域，是路上的风景；价值链条，是路的走向；而人的全面发展，是这条路没有终点的终点。愿每一个劳动者，都能在劳动中安身，在安身中立命，在立命中成为更全面的人。这正是本书的终点，也是劳动科学永恒的起点。从"劳动价值实现"出发，向"人的全面发展"抵达——这条路，值得一代代劳动科学人走下去，也值得每一个读者，用自己的劳动去亲身验证。
