Fromkin · 就业指导师考试教程

第22章 绩效评价方法与组织实施

【本章考纲】

1. 了解绩效评价方法的分类。

2. 掌握常用绩效评价方法的内容、特点与适用范围：比较法、因素分析法、问卷调查法、访谈法、专家评估法、成本效益分析法。

3. 了解目标管理法、平衡计分卡、360度反馈法在绩效评价中的基本应用思路。

4. 掌握评价方法选择的基本原则，能对给定情境选择恰当方法。

5. 熟悉绩效评价组织实施的三个阶段及各阶段主要工作。

6. 掌握数据采集的来源、方法与质量控制要求。

【知识精讲】

第一节 评价方法概述

一、方法的地位

指标体系回答"评什么"，评价方法回答"怎么评"。再科学的指标体系，如果方法不当，也得不出可靠结论。方法选择直接影响评价结果的客观性、准确性和公信力。

二、评价方法的分类

1. 按是否量化分：定量评价方法（用数字说话，如统计分析、成本效益分析）、定性评价方法（用描述和判断说话，如访谈法、专家评估法）、定量与定性相结合的方法（综合评价，最常用）。

2. 按比较基准分：自我比较法（纵向比，与自身历史比）、横向比较法（与同类单位比）、目标比较法（与预定目标比）、标杆比较法（与先进标杆比）。

3. 按信息来源分：直接观察法、记录分析法、调查访谈法、专家判断法。

三、方法运用的总体要求

任何单一方法都有局限，必须根据评价目的、评价对象特点和实际条件选择恰当方法，并坚持定量与定性相结合、多种方法相互印证。

第二节 比较法与因素分析法

一、比较法

1. 含义：比较法是通过对比分析来判断绩效优劣的方法，是最基本、最常用的评价方法。"有比较才有鉴别"，脱离比较的绩效数字没有意义。

2. 主要类型：

- 纵向比较：与本单位历史同期比，看进步还是退步。如今年职业介绍成功人次比去年增长多少。

- 横向比较：与同类单位比，看位次和差距。如各区服务满意度排名。

- 目标比较：与预定目标任务比，看完成程度。如目标任务完成率。

- 标杆比较（标杆管理法）：以行业内先进单位为标杆，找差距、学经验、定措施。不仅比结果，更要学过程、学管理。

3. 优点：简单直观、易于理解、可比性强。

4. 局限：可比条件要大体一致，否则比较不公平；只能说明差距，不能直接揭示原因。

5. 运用要点：统一口径、注意可比性；多种比较结合使用，结论更可靠。

二、因素分析法

1. 含义：因素分析法是将综合绩效指标分解为若干影响因素，逐一分析各因素对总指标的影响程度和影响方向的方法。

2. 举例：职业介绍成功人次下降，可以分解为岗位信息数量、岗位信息质量、人岗匹配精准度、求职者求职意愿等因素，逐一排查主因。

3. 优点：能深入揭示绩效变化的原因，为改进提供针对性依据。

4. 局限：因素分解需要专业判断；因素之间相互影响，完全量化分解有难度。

5. 运用要点：先定性分析理清因素关系，再定量测算影响程度；抓主要矛盾，抓住关键因素。

第三节 问卷调查法与访谈法

一、问卷调查法

1. 含义：问卷调查法是设计结构化问卷，向服务对象、工作人员等发放填写，收集评价信息的方法。是了解群众满意度最常用的方法。

2. 优点：覆盖面广、成本较低、便于量化统计、匿名性强（被调查者敢讲真话）。

3. 局限：问卷设计质量直接影响结果；回收率和有效填写率需要保障；难以深入追问原因。

4. 运用要点：

- 问卷设计：问题简明、选项互斥、避免诱导性提问；先试测再发放。

- 抽样：科学抽样，保证样本代表性；样本量要充足。

- 发放回收：多渠道发放（现场、电话、网络）；提高回收率和有效率。

- 统计分析：如实统计，对异常数据要核查，不随意剔除。

二、访谈法

1. 含义：访谈法是评价人员与访谈对象面对面（或电话、视频）交谈，深入了解情况、听取意见的方法。

2. 类型：结构化访谈（按提纲逐项问）、半结构化访谈（有提纲但可追问，最常用）、非结构化访谈（开放式交谈）。

3. 优点：深入具体，能追问原因，发现问卷发现不了的问题；能观察受访者的态度和情绪。

4. 局限：耗时较长、覆盖面小；受访谈者表达能力和访谈者技巧影响大；记录整理工作量大。

5. 运用要点：事先拟定提纲；营造宽松氛围；多听少说、适时追问；做好记录并及时整理；注意为受访者保密。

三、两者的配合

问卷调查法"面广量大"，访谈法"深入具体"。实践中常用问卷调查发现问题线索，再用访谈深挖原因，两者相互补充、相互验证。

第四节 专家评估法与成本效益分析法

一、专家评估法

1. 含义：专家评估法是组织相关领域专家，运用专业知识和经验对评价对象进行判断打分的方法。常用于难以量化的事项，如管理水平、创新举措、社会影响等。

2. 常用形式——德尔菲法：匿名征询专家意见，经过多轮反馈、逐步收敛，最终形成比较一致的结论。特点是匿名性、多轮反馈、统计收敛，能避免"权威主导"和"随大流"。

3. 优点：能处理复杂、模糊、难以量化的问题；集中集体智慧。

4. 局限：受专家主观判断影响；组织成本较高、周期较长；专家选择不当会影响结论质量。

5. 运用要点：专家要有代表性和权威性；评价标准要事先明确；打分要独立、匿名；对分歧较大的事项要组织讨论或复评。

二、成本效益分析法

1. 含义：成本效益分析法是比较评价对象的投入成本与产出效益，判断其经济合理性的方法。回答"花得值不值"的问题。

2. 基本思路：核算投入的总成本，估算产出的总效益（包括直接经济效益和社会效益），比较效益与成本的关系。效益大于成本，说明投入是值得的。

3. 优点：强化成本意识和效益观念，防止不计成本、铺张浪费。

4. 局限：就业服务的社会效益难以完全货币化，精确计算有难度；过分强调经济效益可能忽视公益性和公平性。

5. 运用要点：成本核算要全面，不遗漏隐性成本；效益估算要实事求是，不夸大；社会效益可采用定性描述与定量估算相结合的方式。

第五节 目标管理法、平衡计分卡与360度反馈法简介

一、目标管理法

1. 基本思想：由组织与个人共同制定具体、可衡量的目标，期末对照目标检查完成情况进行评价。特点是"自我控制、结果导向"。

2. 在就业服务评价中的应用：年初下达目标任务（如服务人次、成功率、满意度目标），年终对照目标完成情况进行评价。目标要具体明确、具有挑战性又可实现。

3. 优点：目标明确、责任清晰，能调动被评价对象的主动性。

4. 局限：目标制定需要充分协商，否则易流于形式；过分关注目标可能忽视过程和意外贡献。

二、平衡计分卡简介

1. 基本思想：从财务、客户、内部流程、学习与成长四个维度全面评价组织绩效，防止单一维度评价的片面性。

2. 对就业服务的启示：公共就业服务可借鉴其"多维度平衡"思想，从资源投入、服务对象、内部管理、能力建设四个维度设计指标，避免"唯数量论"。

3. 注意：平衡计分卡源于企业管理，直接套用要结合公益性质进行改造，不照搬财务指标。

三、360度反馈法简介

1. 基本思想：由上级、同级、下级、服务对象及本人等多方面主体对评价对象进行全方位评价，避免单一主体评价的片面性。

2. 在就业服务评价中的应用：对就业服务人员的评价，可综合上级评价、同事互评、服务对象评价和自我评价，结果更全面客观。

3. 优点：评价主体多元，结论更全面；缺点是组织工作量大，对评价者的素质要求高。

第六节 评价方法的选择与综合运用

一、方法选择的原则

1. 适用性原则：方法要与评价目的、评价对象特点相匹配。评满意度用问卷调查，评管理水平用专家评估，找差距用比较法，挖原因用因素分析。

2. 可行性原则：考虑时间、人力、经费、技术等实际条件，选择做得到、做得起的方法。

3. 经济性原则：以尽可能低的成本获得满足需要的信息，避免"杀鸡用牛刀"。

4. 互补性原则：扬长避短，多种方法组合使用，相互印证。如定量打分与定性访谈结合，问卷调查与实地核查结合。

二、综合运用的基本思路

实践中不存在"一种方法包打天下"。正确的做法是：以一两种方法为主，其他方法为辅；定量方法得出"是什么"，定性方法解释"为什么"；多种来源的数据相互验证，结论才可靠。考试答题表述为"坚持定量与定性相结合、多种方法综合运用、相互印证"。

第七节 评价组织实施流程之一：准备阶段

一、成立评价组织

1. 明确评价的组织领导，成立评价工作组或委托第三方机构。

2. 合理分工：组织协调、数据采集、分析评价、监督保障等职责到人。

3. 强调纪律：评价人员要客观公正、遵守保密纪律、不得弄虚作假。

二、制定评价方案

评价方案是评价工作的"施工图"，主要内容包括：评价目的、评价对象与范围、评价指标体系与权重、评价方法、评价标准、组织分工、时间安排、数据采集要求、结果运用方式、纪律要求等。方案要报经批准后实施。

三、宣传培训与动员

1. 宣传动员：讲清评价的目的意义，消除被评价对象的顾虑，争取理解配合。

2. 业务培训：对评价人员和被评价单位经办人员进行培训，统一指标口径、数据采集方法和报送要求。

3. 特别强调：评价是"体检"不是"找茬"，目的是改进工作，这个导向要在动员中讲清楚。

第八节 评价组织实施流程之二：实施阶段

一、数据采集

按方案要求采集评价所需数据（详见第十节）。这是评价的基础环节，数据质量决定评价质量。

二、实地核查

1. 为什么核查：书面材料和报表数据可能失真，实地核查是验证数据真实性的关键手段。

2. 核查方式：听汇报、查台账、看现场、访对象、调系统数据交叉比对。

3. 核查重点：数据的真实性、台账的完整性、服务的规范性、群众的真实感受。

4. 核查纪律：轻车简从，不干扰基层正常工作；发现问题当场指出、要求说明。

三、分析评价

1. 对照指标体系和评价标准，对采集的数据进行整理、计算、分析。

2. 定量分析与定性分析结合，既看分数排名，更看问题成因。

3. 形成初步评价意见，对存疑数据要复核，对重大问题要深入调查。

第九节 评价组织实施流程之三：总结阶段

一、形成评价报告

评价报告是评价工作的集中成果，主要内容包括：评价工作概况、评价结果（总体情况、分类结果）、主要成绩与亮点、存在的问题与不足、原因分析、改进建议。报告要实事求是，成绩不夸大，问题不回避，建议有针对性、可操作。

二、反馈沟通

1. 将评价结果向被评价对象反馈，听取意见，允许申诉和复核。

2. 反馈不是单向"宣布"，而是双向沟通：既肯定成绩，也指出问题，共同商讨改进措施。

3. 对评价结果有异议的，要按程序复核，给被评价对象说话的机会，这是保证评价公正的重要环节。

三、结果运用

按既定方案运用评价结果（详见第23章）。评价不停留在"评"，落脚点在"用"和"改"。

四、资料归档

评价方案、数据资料、评价报告、反馈记录等全部归档保存，做到全过程可追溯。归档既是工作规范，也是应对复查、审计的需要。

第十节 数据采集

一、数据来源

1. 业务台账：最主要、最直接的来源，服务的原始记录。

2. 业务信息系统：系统自动生成的业务数据，客观性强。

3. 统计报表：定期报送的统计数据，需核验真实性。

4. 问卷调查：服务对象满意度等主观感受类数据。

5. 实地核查：现场查看、访谈了解的一手资料。

6. 相关部门数据：社保、市场监管等部门的共享数据，用于交叉验证。

二、数据采集方法

1. 直接提取：从业务系统和台账中直接提取，注意统一提取口径和时间节点。

2. 填报报送：设计统一报表，由被评价单位填报；要附填报说明，明确口径。

3. 调查获取：通过问卷、访谈、实地查看获取书面上没有的数据。

4. 共享交换：通过部门间数据共享获取验证性数据。

三、数据质量控制

数据质量是评价的生命线，要从四个方面把关：

1. 真实性：数据真实可靠，不虚报、不瞒报、不造假。对异常波动数据要追查原因。

2. 完整性：数据项目齐全，不缺项、不漏报；时间连续，前后衔接。

3. 准确性：计算方法正确，口径统一，单位无误，小数点、数量级不出错。

4. 时效性：数据反映评价周期内的实际情况，按时报送，不拖延、不提前"预支"。

四、防范数据造假

1. 思想上：加强教育，让被评价对象认识到造假的危害和后果。

2. 制度上：建立数据核查和责任追究制度，对造假实行"一票否决"。

3. 技术上：多源数据交叉验证，系统自动校验与人工抽查结合。

4. 监督上：畅通举报渠道，发挥群众监督作用。

第十一节 评价中的常见偏差及纠正

一、为什么会产生偏差

评价是人做的事，人的主观心理必然带来偏差。了解常见偏差，才能有意识地防范，保证评价客观公正。

二、常见偏差类型

1. 晕轮效应：以偏概全，因某一个突出优点或缺点而推及其他方面。如某单位宣传工作做得好，就认为其各项工作都好。

2. 近因效应：以近期表现代替全期表现。如只看年底突击取得的成绩，忽视全年工作的平平。

3. 宽大倾向与严格倾向：评价者打分普遍偏高（老好人）或普遍偏低（苛刻），导致区分度丧失。

4. 趋中倾向：为避免矛盾，所有对象都打中间分，谁也不得罪，评价流于形式。

5. 个人偏见：因个人好恶、关系亲疏影响评价，丧失客观立场。

6. 刻板印象：用固定看法评价对象，如"小单位肯定不如大单位"，忽视实际情况。

三、纠正偏差的措施

1. 统一评价标准和尺度，减少主观随意性。

2. 评价者培训：讲清常见偏差，提高评价者的自我警觉。

3. 多人评价、取平均值或去掉最高最低分，稀释个人偏差。

4. 以事实和数据为依据，用证据说话，不用印象说话。

5. 评价过程公开透明，接受监督，让偏差无处藏身。

【必背要点】

1. 指标体系回答"评什么"，评价方法回答"怎么评"；方法选择直接影响评价的客观性、准确性和公信力。

2. 方法分类：按是否量化分定量、定性、定量与定性相结合；按比较基准分自我比较、横向比较、目标比较、标杆比较。

3. 比较法：纵向比看进步、横向比看差距、目标比看完成、标杆比学经验；优点是简单直观，局限是只能说明差距不能直接揭示原因。

4. 因素分析法：将综合指标分解为影响因素，分析各因素影响程度；能揭示原因，抓主要矛盾。

5. 问卷调查法：覆盖面广、成本低、便于量化、匿名性强；要点是科学设计、科学抽样、保证回收率、如实统计。

6. 访谈法：结构化、半结构化、非结构化；深入具体、能追问；要点是拟定提纲、多听少说、做好记录、注意保密。

7. 专家评估法：用于难以量化事项；德尔菲法特点是匿名、多轮反馈、统计收敛。

8. 成本效益分析法：回答"花得值不值"；社会效益难以完全货币化，要定性定量结合。

9. 目标管理法：共同制定目标、期末对照检查，自我控制、结果导向。

10. 平衡计分卡：多维度平衡思想可借鉴，不照搬企业财务指标；360度反馈：多主体全方位评价。

11. 方法选择四原则：适用性、可行性、经济性、互补性；坚持定量与定性结合、多种方法相互印证。

12. 评价组织三阶段：准备阶段（成立组织、制定方案、宣传培训）、实施阶段（数据采集、实地核查、分析评价）、总结阶段（形成报告、反馈沟通、结果运用、资料归档）。

13. 评价方案内容：目的、对象范围、指标体系权重、方法、标准、分工、时间安排、数据要求、结果运用、纪律要求。

14. 数据来源：业务台账、业务系统、统计报表、问卷调查、实地核查、部门共享数据。

15. 数据质量控制四性：真实性、完整性、准确性、时效性。

16. 防范数据造假：思想教育、制度约束（"一票否决"）、技术核验（交叉验证）、群众监督。

17. 常见评价偏差：晕轮效应、近因效应、宽大/严格倾向、趋中倾向、个人偏见、刻板印象；纠正：统一标准、评价者培训、多人评价取平均、用事实数据说话、过程公开透明。

【记忆口诀】

口诀一：六法"比因问访专成本"

比较因素问卷访，专家成本六法强；定量定性相结合，相互印证才可靠。

（比较法、因素分析法、问卷调查法、访谈法、专家评估法、成本效益分析法）

口诀二：选法四原则"适可行互补"

适用可行经济性，互补搭配扬长避；量定结合多印证，方法选对方受益。

（适用性、可行性、经济性、互补性）

口诀三：三阶段九环节"备实结"

准备成立组织定方案，宣传培训先动员；实施采集核查加分析，总结报告反馈用归档。

（准备阶段：成立评价组织、制定评价方案、宣传培训动员；实施阶段：数据采集、实地核查、分析评价；总结阶段：形成评价报告、反馈沟通、结果运用、资料归档）

口诀四：数据质量"真完准时"

真实完整准确性，时效四性严把关；多源交叉防造假，一票否决震慑严。

（真实性、完整性、准确性、时效性）

【章后练习】

以下为模拟练习题（非真题），供自我检测：

一、单项选择题

1. "有比较才有鉴别"，下列属于标杆比较的是（ ）。

A. 今年与去年比 B. 本区与邻区比

C. 实际与目标比 D. 以行业先进单位为参照找差距

【答案】D。解析：A是纵向比较，B是横向比较，C是目标比较，D是以先进为标杆的标杆比较。

2. 了解服务对象满意度最常用的方法是（ ）。

A. 因素分析法 B. 问卷调查法 C. 成本效益分析法 D. 比较法

【答案】B。解析：问卷调查法覆盖面广、匿名性强，是测量满意度的首选方法。

3. 德尔菲法的突出特点是（ ）。

A. 面对面辩论 B. 匿名、多轮反馈、统计收敛

C. 完全定量计算 D. 只需一轮征询

【答案】B。解析：匿名性能避免权威主导和随大流，多轮反馈使意见逐步收敛。

4. 评价工作的"施工图"是指（ ）。

A. 评价指标体系 B. 评价方案 C. 评价报告 D. 宣传提纲

【答案】B。解析：评价方案规定目的、对象、指标、方法、分工、时间等，是指导评价全过程的施工图。

二、多项选择题

5. 数据质量控制的要求包括（ ）。

A. 真实性 B. 完整性 C. 准确性 D. 时效性 E. 海量性

【答案】ABCD。解析："真完准时"四性；海量性不是质量要求。

6. 访谈法的类型包括（ ）。

A. 结构化访谈 B. 半结构化访谈 C. 非结构化访谈 D. 电话访谈 E. 问卷访谈

【答案】ABC。解析：按结构化程度分三类；DE是按实施方式分，不是规范分类。

7. 评价实施阶段的主要工作包括（ ）。

A. 数据采集 B. 实地核查 C. 分析评价 D. 制定方案 E. 宣传培训

【答案】ABC。解析：DE属于准备阶段的工作。

三、判断题

8. 评价方法越多越好，把所有方法都用一遍结论最可靠。（ ）

【答案】×。解析：违背可行性、经济性原则；应根据需要选择恰当方法组合，讲求互补而非堆砌。

9. 实地核查是验证数据真实性的关键手段，核查要轻车简从、不干扰基层正常工作。（ ）

【答案】√。解析：书面材料可能失真，实地核查必不可少；同时要遵守核查纪律。

10. 对评价结果有异议的被评价对象，有权按程序申诉和要求复核。（ ）

【答案】√。解析：申诉复核是保证评价公正的重要环节，反馈沟通必须是双向的。

四、简答题

11. 简述评价方法选择的四项原则。

【参考答案】适用性（与目的、对象特点匹配）、可行性（条件允许、做得到）、经济性（低成本获取所需信息）、互补性（多种方法组合、相互印证）；坚持定量与定性相结合。

12. 简述绩效评价组织实施的三个阶段及各阶段主要工作。

【参考答案】准备阶段：成立评价组织、制定评价方案、宣传培训动员；实施阶段：数据采集、实地核查、分析评价；总结阶段：形成评价报告、反馈沟通、结果运用、资料归档。

五、案例分析题

13. 某市对就业服务机构评价只采用了年终报表数据汇总排名，没有实地核查，也没有听取服务对象意见，结果排名靠前的单位群众投诉却最多。请分析问题并提出改进建议。

【参考答案】问题：（1）方法单一，只有报表汇总，违背多种方法综合运用、相互印证的要求；（2）缺少实地核查，数据真实性未经验证；（3）缺少服务对象评价，违背以群众满意为根本标准的要求；只看报表数字，数字可能失真。改进：（1）综合运用比较法、问卷调查法、访谈法、实地核查等多种方法；（2）把服务对象满意度作为重要评价内容；（3）建立数据交叉验证机制，对异常数据实地核查；（4）评价结果与群众感受相互印证，出现背离要深入调查原因。

六、论述题

14. 试述如何保证绩效评价数据采集的质量。

【参考答案】（1）拓宽数据来源：业务台账、业务系统、统计报表、问卷调查、实地核查、部门共享数据，多源相互验证；（2）规范采集方法：统一口径和时间节点，明确填报要求；（3）严把质量四关：真实性（不虚报瞒报）、完整性（不缺项漏报）、准确性（口径计算无误）、时效性（按时报送）；（4）防范造假：思想教育、制度约束与"一票否决"、技术交叉验证、畅通监督举报；（5）实地核查验证，对异常数据追查原因。
